# 原申报书与挑战杯蓝图来源对照

## 判定口径

本表基于已审阅的导师申报书与 `09_project_blueprint_v0_1.md`。标签含义：`CONSISTENT` 一致；`INTENTIONALLY_NARROWED` 为竞赛执行边界而有意收窄；`MISSING_FROM_BLUEPRINT` 原方案有但v0.1未呈现或只略写；`NEW_STUDENT_CONTRIBUTION` 为学生为形成独立竞赛作品新增的设计；`CONFLICT_NEEDS_SUPERVISOR` 存在范围冲突/原意无法判定。

## 逐项对照

| 题目：生成式AI对财经类专业本科生科研创新能力的影响机制与提升路径 | v0.1聚焦AI参与财经本科生研究任务、核验行为与任务表现 | INTENTIONALLY_NARROWED | 保留AI与学生研究能力主题，将宽泛结果操作化；不照搬教师课题为竞赛成品 |

## 总结判断

现有证据不支持“主题已漂移到另一个研究问题”：v0.1仍围绕生成式AI与财经本科生科研任务/能力。它是为挑战杯执行而进行的**有意压缩与测量化**，不是对原申报书四专题、四假设及三年计划的完整复刻。原申报书提及挑战杯作为教育实践场景和成果应用背景，但不是本届正式参赛方案。企业数据为何一并提供仍属 `CONFLICT_NEEDS_SUPERVISOR`，不能据现有文件强行纳入。

## 必须由导师/团队补充确认

1. “财经类专业本科生”的总体边界及是否必须覆盖原五维；
2. 企业招聘/上市公司材料是方法参考还是项目强制正式数据；
3. 目标届次、资格、团队情况、截止日期与样本渠道；
4. 学生问卷/访谈/任务评价的伦理审批与数据管理流程。
