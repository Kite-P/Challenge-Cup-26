## 暂定题目与核心问题

**暂定题目：**会用AI，还是会与AI做研究？财经类本科生科研任务中的人机协作与证据核验调查。

**核心问题：**财经类本科生在研究型任务哪些环节使用生成式AI、如何核验其输出；不同协作方式与可观察任务表现及培养需求之间呈现何种关系？本设计不预设正向结果，也不把横截面相关写成因果影响。

## 对象与研究范围

- **原申报书总体：**财经类专业本科生，包括财经类高校学生及综合高校财经相关专业；定义和题目措辞存在边界差异，需导师确认。
- **v0.2暂定范围：**以有机会接触财经/商科本科生的研究型学习任务为中心。学校数量、专业/年级覆盖、抽样框和样本量均不预设，先核验团队渠道和当前赛期。
- **学生端为主：**学生调查/访谈和经批准的短研究任务构成候选一手证据。企业招聘和上市公司材料不进入核心分析。
- **学生主导：**工具设计、招募和知情同意、测量、评分规则、数据整理、分析决策与竞赛作品需由学生实际参与并留存过程记录。

## 概念框架（待测量验证）

`AI协作方式/质量` → `证据核验与研究方法理解` ↔ `研究任务表现`

任务复杂度、既有方法素养可作为有限的边界因素。关系箭头仅表示候选理论路径，不是已识别因果图。

| 构念 | 候选观测内容 | 边界 |
|---|---|---|
| AI协作方式/质量 | 使用环节、提示迭代、反例/证据要求、来源/数字/引文核验、代码理解和最终判断权 | 避免把使用频率当作协作质量的唯一指标 |
| 核验与方法理解 | 交叉检查、辨认不确定性、解释变量/方法、发现输出错误 | 需开发可观察项目或评分规则，不以自我感觉替代 |
| 任务表现 | 问题界定、资料整合、方法适配、证据解释、论证表达 | 若采用短任务，需盲评规则、评分者校准及伦理批准 |
| 风险 | 未核验采纳、依赖、浅层加工、诚信规范认知 | 风险需谨慎测量，不预设发生率或方向 |
| 候选边界因素 | 任务复杂度、先前方法素养；教师指导可访谈/描述 | 后续仅保留少量有理论与样本支持的因素 |

## 候选证据与方法

1. 文献与概念梳理；
2. 学生问卷和半结构访谈；
3. 经导师与伦理/校内审批的短研究任务与评分量规（是否实施待确认）；
4. 描述性分析、测量/评分一致性和多源证据互证；只有设计、样本与测量支持时，才考虑有限的关联模型。

不把SEM、DID、IV、PSM或企业固定效应回归作为默认方案；不作强因果结论。

## 数据角色

- **主要数据：**经批准的学生一手调查/访谈/任务材料，当前尚未采集。
- **辅助来源：**公开课程、政策或文献材料；只有合法访问且与问题相关时使用。
- **企业材料：**导师所给DTA、`.do`、复现包可供方法学习；招聘数据产品可供背景评估。导师是否要求正式纳入尚无法判断（分类C），因此v0.2中均不作为正式主数据，不下载、不购买、不运行。

## 预期竞赛作品形式与贡献

若导师确认Route A、赛期可行且伦理审批通过，候选交付为学生主导的调查报告/研究作品，配套研究任务与核验评分框架、匿名化结果图表、面向财经类课程的证据化建议及答辩展示。所有内容均属拟议，不是已完成成果或效果承诺。

## 最大风险与回退

- 竞赛届次、报名资格和截止日期未知；若未进入当前轮次，重排到真实可报名届次。
- 样本渠道和伦理流程未确认；若任务评价不能实施，退回经批准的问卷/访谈描述研究，并收窄结论。
- 构念测量/盲评一致性不足；先修订工具，不以复杂模型掩盖测量问题。
- 企业数据授权、来源与导师意图未确认；不将其作为主线依赖。
