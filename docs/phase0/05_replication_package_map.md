## 源码模块

- `reghdfe`企业/年份等固定效应回归、事件研究/平行趋势、500次置换安慰剂；
- PSM-DID（`psmatch2`、`pstest`）、含两个工具变量的IV（`ivreghdfe`）、DDD；
- 其他稳健性包含替代TFP、滞后结果、替代处理变量/文本指标、样本切换及控制宽带中国政策；
- 机制涉及管理费用/基金周转/资产周转、研发/专利、机器人设备/暴露、教育/技能/培训、融资约束/补贴；
- 异质性涉及数字基础设施、企业数字化、技术升级、劳动力/规模等；经济结果含收入、市场份额、风险/Z值等；
- 输出依赖`esttab`、`coefplot`，另识别到`dpplot`及`qlean`图形方案。外部命令包括`reghdfe`、`esttab`、`coefplot`、`ivreghdfe`、`psmatch2`、`pstest`、`dpplot`；没有验证其在本机Stata中的安装状态。

源码含一处硬编码输出路径；为避免泄露本机/他人绝对路径，本报告不复述该路径，也未运行代码。
