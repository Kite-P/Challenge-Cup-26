# 项目蓝图 v0.1（暂定，待导师与赛期确认）

## 暂定题目

**生成式人工智能参与财经本科生科研任务的方式、核验行为与任务表现：一项学生主导的调查研究**

## 候选题目（供导师和团队讨论）

### 学术型

1. 生成式人工智能协作质量与财经类本科生研究任务表现：基于过程核验与方法理解的调查
2. 从工具使用到人机协作：生成式人工智能参与财经本科生科研任务的行为测量研究
3. 生成式人工智能使用、证据核验与本科生研究能力表现：财经类学生的多源调查

### 挑战杯调查报告型

4. AI进入财经本科生科研训练之后：研究任务使用、核验行为与能力培养需求调查
5. 会用AI，还是会与AI做研究？财经类本科生科研任务的人机协作现状调查
6. 从生成答案到核验证据：财经本科生使用生成式AI开展研究型学习的调查与建议

### 传播性较强但保持严谨

7. AI给出答案之后：财经本科生如何核验、理解并完成研究任务
8. 把AI请进研究过程：财经本科生人机协作方式与科研训练改进调查
9. 从“生成”到“求证”：财经本科生与生成式AI协作完成研究任务的真实记录

**首选暂定题目：**“会用AI，还是会与AI做研究？财经类本科生科研任务的人机协作现状调查”。它用可观察的任务冲突替代预设正负效应，保留学生调查报告的可读性；如果正式任务测量未获批准或不可行，应改为纯调查题名，不声称任务表现已被测量。

## 问题与边界

- **一句话问题：**财经类本科生在科研任务的哪些环节以何种质量与生成式 AI 协作，这些协作方式与其可观察的研究任务表现、核验行为及潜在依赖风险如何相关？
- **现实痛点：**“是否使用AI”无法反映学生是否审查答案、理解方法与代码、交叉核验来源；单靠自我感觉也未必代表真实任务能力。项目不预设 AI 必然提高能力。
- **对象：**优先财经/商科本科生；是否跨校、年级和专业，由可联系渠道与竞赛要求共同决定。
- **边界：**聚焦研究型学习任务，不泛化到全部学习成绩、就业能力或所有高校；不把相关性写成因果结论。
- **为什么财经学生：**原课题对象如此设定，且任务可设计为财经议题的资料核验、变量/指标理解和证据表达。该理由仍需通过导师原申报书和可接触样本复核。
- **为什么现在：**生成式 AI 已成为待研究的学习/研究工具，官方校赛公开项目中已有面向 AI 时代就业预测、AIGC 与具体服务场景作品；这只表明议题出现，不证明效果方向。[中传2025公示](https://xxgk.cuc.edu.cn/2025/0407/c5356a254076/page.htm)

## CORE MODEL（概念框架，不是已验证模型）

`AI协作质量/方式` → `研究方法理解与证据核验` → `研究任务表现`

任务难度、先前方法素养可作为边界因素。因果方向、变量可靠性与模型形式均待测量开发和小样本试测；若只有横截面问卷，则结果只能表述为条件相关。

| 角色 | 候选测量（概念层） |
|---|---|
| 核心解释变量 | 使用频率与具体研究阶段；提示迭代/追问深度；要求证据与反例；是否交叉核验来源；是否核验数字、引文、计算；是否理解/调试AI生成代码；最终决策由人判断还是直接照搬。形成“答题机器—研究协作者”的多维连续测量，不用单一0/1替代。 |
| 结果变量 | 标准化短研究任务的盲评维度：问题界定、来源整合、方法选择及假设识别、数据/证据解释、论证表达；自评五维能力作辅助，不单独作为成效结论。 |
| 核心中介候选 | 证据核验行为与研究方法理解（两者先比较，不默认双中介同时入模）。 |
| 调节/分层候选 | 先前方法素养；任务复杂度。先验理论与样本支持后择一。 |
| 风险结果 | 未核验采纳、方法/代码误解、过度依赖、浅层加工自陈；学术诚信规范意识另作描述性模块。 |
| 控制变量 | 年级、专业方向、既往研究训练、课程统计/方法学习、既有AI经验、任务熟悉度等，避免过度控制中介或后处理变量。 |

## 备用模块（RESERVE MODULES）

1. 教师指导支持（访谈/分层描述）。
2. 任务复杂度与不同研究环节（探索性异质性）。
3. AI依赖、浅层加工与诚信规范风险。
4. 企业岗位技能需求与学生能力供给映射（Route C），须等数据许可、分类规则和测量可比性通过再开展。
5. 若后续确有清晰随机任务设计，可另行申请/确认伦理后做小规模行为实验；本阶段不实施。

## 拟用证据与样本设计

- **一手数据：**问卷、半结构访谈、短研究任务及事先制定的评分量规；完成知情同意、匿名化与退出设计后方可采集。
- **调查对象：**目标财经/商科本科生；抽样框、学校数、样本量现在均不预设，先由渠道盘点决定可行边界。
- **访谈对象：**学生（不同AI协作经验/训练经历）；教师可作为补充视角。人数由信息饱和与资源决定，不编造数字。
- **任务范例：**给定一段可核验的财经公开材料与一个简短分析问题，观察资料核对、指标解释、方法适配与论证修订；任务材料需避免用真实课程成绩做研究结果。
- **二手数据：**只在可合法访问且确有研究价值时引用公开政策/课程文件或招聘数据；暂不将上市公司控制变量用于主模型。
- **企业招聘数据：**目前建议不进入主研究；可作为 Route C 的后续扩展，不购买、不下载，待导师确认用途与许可。

## 分析、展示与产出

- 先做描述性分析、量表/评分一致性检查、访谈主题归纳与问卷—任务证据互证。
- 在样本、量表和设计满足后，估计简化关联模型并做预先说明的敏感性检查；不自动上 SEM、DID、IV、PSM 或机器学习。
- 预期图表：研究任务流程图；AI协作质量维度图；核验行为分布；不同任务表现维度的盲评分布；访谈主题与量化结果对照；教学建议—证据映射表。
- 预期成果：可复用的研究任务与评分量规、匿名化调查分析、对财经类课程的 AI 核验/协作建议、竞赛报告与答辩展示材料。均为计划，不是承诺的实证发现。
- 教学产品原型可包括“AI协作核验清单+一页任务评分表”，先邀请导师审阅，再考虑试用。

## 挑战杯化：学生贡献与流程

教师原申报书只提供问题背景与概念线索，不能整段换题沿用。学生须新增：学生主导的实地/实际调查；将问题缩到可观察的研究型学习任务；自己制定并记录招募、同意、测量、评分和分析规则；保存匿名化原始证据与修订记录；由学生完成主要分析、结论边界与展示。首经贸上一轮官方规则明确要求社会调查数据/访谈由学生独立或深度参与获得，但其时段已过；当前轮须重新确认。[上一轮规则（历史参照）](https://cba.cueb.edu.cn/xzsy/e68744f8586a4c6a8bfab9f28015632f.htm)

## 最大风险与 fallback

- **最大风险：**尚未确认目标轮次/团队参赛资格、校内截止时间与跨校样本渠道；其次是用自评代替能力表现、任务评分主观性、学生参与伦理和横截面因果夸大。
- **Fallback：**先收窄为一所/可达范围内的财经本科生研究任务案例，采用访谈+小样本任务评分与描述性报告；如果样本不足，明确限制外推并把作品转为“测量框架/教学工具的可行性试点”，不得伪称总体影响。
- 若校内竞赛窗口已错过，先由导师/校团委确认下一轮，Phase 1 不以旧通知日期为截止日期。
