# 社会调查报告骨架候选

状态：`REFERENCE`，仅规划结构；须服从未来正式竞赛规则与真实证据。

1. 摘要：问题、对象、方法、主要发现、边界（不得虚构结果）。
2. 问题提出：现实背景、文献依据、研究问题和范围。
3. 研究设计：总体/抽样/审批、测量与材料、数据收集及质量控制。
4. 结果：样本流、核心描述、任务表现、预设关联；缺失与反例一并报告。
5. 讨论：与文献对照、解释竞争、选择/测量/外推限制。
6. 建议：每条连接到具体结果、实施主体与可行条件；证据不足时标为待验证。
7. 局限与后续：不得以未来计划冒充已完成工作。
8. 附件：工具版本、数据说明、合规材料和可复核接口（仅在规则/许可允许时）。

本骨架不要求堆叠模型或构念，也不意味着已有调查或报告结论。
