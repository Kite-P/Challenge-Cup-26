# 二手数据进入挑战杯成果的规则决策树

当前届次/适用规则 `PENDING_OFFICIAL_RULES`；此树只供将来核规则，不替代正式通知。

1. **正式规则是否允许使用二手岗位文本？**
   - 否或未明确：不将岗位文本放入核心实证；继续以经批准的学生调查为主体，必要时仅列一般背景或不使用。
   - 是：继续核对规则对原创调查、主要数据和团队实质参与的要求。
2. **是否要求主要证据来自团队亲自调查？**
   - 是：岗位文本必须明确为补充，不能改变主体；报告学生调查过程证据。
   - 未知：请求官方规则澄清的人工决定触发时再处理；本轮不联系。
3. **是否要求团队深度参与全部关键数据？**
   - 是：需评估人工岗位筛选/编码、复核日志和可能的一手需求侧材料是否可行；不以自动抓取或 LLM 代替团队实际研究。
   - 否：仍须取得来源许可并保留人工解释证据。
4. **数据许可/字段/时间范围是否足够？**
   - 否：不获取、不编码、不报告岗位实证；记 `RECRUITMENT_DATA_NOT_YET_AVAILABLE`。
   - 是：单独完成数据审批与岗位编码预案后再启动。

当前没有可走到“执行”的分支。企业方向仍属已确认补充规划，是否满足本届规则需要官方材料核验，不能提前作结论。
