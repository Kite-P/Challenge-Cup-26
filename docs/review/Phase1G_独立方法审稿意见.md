# Phase 1G 独立方法审稿意见（第二遍视角复核）

审阅视角：严格方法审稿人。**这是项目组对抗式复核记录，不是外部独立专家意见或同行评审。**

## MAJOR

1. **总体与样本框尚未可操作。**“财经相关本科生”需冻结专业代码/边界并拿到合法学校与专业框。目录只能定义分类，不能提供抽样框。结论：未解决，影响未来外推。
2. **构念效度未验证。**信息辨识与评估、方法理解与适配、独立研究决策均为工作构念；文献中的邻近量表不等于本工具效度。静态题审不能代替获批认知访谈/可行性验证。
3. **问卷自报与单次任务来源不同、分母不同。**不得汇总为单一能力分数或称问卷/任务互为金标准；若不获批准建立链接，只能分别描述。
4. **任务可评分性和表达能力混杂。**需进一步明确“未观察到”与“能力不足”、阅读负荷、任务时间和AI可及性；合成材料无法估计真实负担。
5. **便利抽样及学校聚类风险。**即便得到多校样本，学校数量和渠道仍决定能否作跨校比较；当前没有依据设定 N 或权重。
6. **岗位 taxonomy 尚无文本验证。**八维分类主要由设计推导与学生构念映射，岗位文本许可和人工双编码尚未发生，不应进入结果叙述。

## MODERATE

- 问卷审计指出若干重复条目/负担点；需导师审阅后先删减而不是新增构念。
- 评分分项重叠仍需用边界案例核查；weighted kappa 受稀疏类别影响，报告不可估状态并同时展示原分布。
- 访谈提纲避免评价单个学生，但访谈角色/选样和权力关系尚待机构审阅。
- 缺失、排除、极短时长规则不能在见到真实结果后决定；当前阈值维持未定是正确的。

## MINOR

- 中英文旧构念词在大量历史材料、schema 字段和引文中仍可见，必须依文档分类读，不做机械全局替换。
- “AI协作方式”属于主线描述域，未被定义为单一量表构念；报告需继续避免总分化。

## 结论

Phase 1G 内部材料可作为下一次人工/导师审阅基础，但**不满足真人 pilot 条件**。没有 MAJOR 项可以通过文档数量自行关闭；所有外部审批、样本框、工具版本、N、企业许可和真实测量质量仍待核验。最终状态 `PILOT_BLOCKED`。
