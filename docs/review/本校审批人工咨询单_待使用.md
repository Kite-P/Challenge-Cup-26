# 本校审批人工咨询单（待使用，未发送）

**用途：**待研究方案接近正式审阅时，由项目负责人按校方指引选择正式部门咨询。本单不是审批申请或审批结论；本轮没有联系学校。

1. 不收直接身份标识的学生问卷是否需要审批或备案？去标识化及记录关联要求是什么，由哪个部门受理？
2. 10–15分钟短研究设计任务是否需要单独审批或课程/学院许可？
3. 学生访谈与教师访谈分别需要何种审批、备案或知情同意？
4. 访谈录音是否需要单独同意？是否允许仅做不含身份信息的笔记？
5. 记录任务相关AI使用摘要（不含完整提示词/对话）是否有额外要求？
6. 若涉及其他高校学生，首经贸与对方学校分别需要哪些许可及书面材料？
7. 学校要求的参与者信息说明、知情同意、未成年人排除或撤回机制模板是什么？
8. 研究数据允许保存多久，谁可访问，期限届满如何销毁？
9. 项目责任人、导师、学院与伦理/科研管理部门各自承担什么职责？
10. 本项目应向哪个正式部门/入口提交，是否需要导师签字、项目立项或学院审批？

**发送前条件：**研究方案与工具已审阅；确认负责部门；补齐项目负责人和导师信息；不得附真实参与者资料。本文件当前不得直接发送。
