# Phase 1G 竞赛视角审稿意见

审阅视角：大挑社会调查作品评审；此为内部桌面审阅，不代表官方评审或专家意见。

## MAJOR

1. 当前无真实调查和研究发现，无法评价社会价值是否被数据证明；任何获奖/竞争力结论都不成立。
2. 2027 相关通知已发现，但范围限于管理工程学院，且页面列出的院内/校级提交时点在 2025 年末；不能证明本团队所属单位、报名、资格或补报可能性。须以适用官方通知和团队自身记录核实。
3. 二手招聘文本能否作为大挑关键证据取决于正式规则；学生团队真实调查须留有充分可审计过程证据。不得让企业端抢占学生调查主体。
4. 单次小任务不能代替社会调查；其定位应是互补的行为证据，核心报告仍需要可获批、可实施、可说明抽样局限的学生调查。

## MODERATE

- 标题候选有一定学术性，但需避免“从…到…”造成因果/成长路径误读。
- 表图规划较丰富，最终应按真实结果删减；不为“完整”保留所有图表。
- 建议体系必须以问卷/任务/访谈/合法岗位资料中的真实证据回溯，未观测到的政策采纳效果不能表述为已实现。
- 当前官方公开案例只能确认题名、公告范围等信息；未披露的样本、方法、图表和实施效果均标 `UNKNOWN`。

## MINOR

- 中性任务情境降低专业门槛，但不能模拟所有财经研究任务。
- 竞赛合规与研究审批是两道独立门槛，不可用一方通过替代另一方。

## 结论

可继续完善设计和官方规则核验，不可宣称调查完成、团队已具备参赛资格、作品符合当届全部条件或获奖概率。研究继续 `PILOT_BLOCKED`。
