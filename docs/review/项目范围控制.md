# 项目范围控制

任何新增构念、问题、表、模型、样本或工具，在进入候选范围前逐项回答：

1. 是否直接回答已确认研究问题？
2. 是否服务大挑社会调查报告的关键证据链？
3. 现有问卷/任务/访谈是否已有重复模块？
4. 是否增加参与者时间/隐私负担或机构审批复杂度？
5. 是否需要新的样本、学校、企业或数据许可？
6. 是否改变主线或让结论范围超出证据？

若多数问题不能说明直接必要性，记为 `RESERVE` 或 `OUT_OF_SCOPE`，不进入核心工具。不得为了工具包看起来完整不断增加构念、量表或模型。跨到独立研究生申请论文的工作按 `docs/PROJECT_BOUNDARIES.md` 分开管理。
