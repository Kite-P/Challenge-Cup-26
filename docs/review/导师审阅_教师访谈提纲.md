# 导师审阅｜教师访谈提纲 v0.3

**审阅候选；未批准、未试测、未联系或访谈任何教师。**预计20–30分钟为未验证估计。项目保持 `PILOT_BLOCKED`；不得据此招募或实施。

## 目的与边界

了解教师对研究型学习过程中可观察表现、指导支持和常见困难的非识别性观察，辅助解释学生端证据。不是学生能力测验，不评价具体学生，不以教师意见替代学生证据或企业需求材料。不得提供学生名单/作业、未公开校内材料或招聘数据；访谈记录和引用均待审批。

## 主问题

1. 在您接触的研究型学习任务中，学生通常需要完成哪些研究步骤？不同任务要求有何差异？
2. 哪些可观察过程表明学生在形成自己的研究问题或决定？哪些表现容易被误读？
3. 学生如何核对来源、口径和证据范围？哪些过程证据有帮助，常见困难或反例是什么？
4. 学生选择方法会考虑哪些条件？如何说明方法能回答和不能回答什么？
5. 学生如何处理样本、测量、来源或执行限制？什么反馈有助于收窄结论？
6. 如适用，您观察到学生如何使用、核验或不使用生成式 AI？什么证据能看出本人作了判断？
7. 哪类教学活动、指导或反馈有助于学生练习研究过程？有哪些负担或公平风险？
8. 若未来设计短研究任务，您建议避免哪些误导、超范围推断或不必要负担？

使用中性追问，不举可识别案例，不请教师替企业需求背书。完整版见 [`../phase1/instruments/08_teacher_interview_v0_3_supervisor_review.md`](../phase1/instruments/08_teacher_interview_v0_3_supervisor_review.md)。
