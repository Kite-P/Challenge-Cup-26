## 已确认的方向

- 学生端是研究主体：问卷为主要证据，短任务与学生/教师访谈为补充；不预设因果效应。
- 四类学生端证据为问卷、短任务、学生访谈、教师访谈；未来任务统一允许使用生成式 AI，观察协作方式，不设置 AI/无 AI 对照（仍受审批约束）。
- 主线保持克制：**AI 协作方式 → 信息辨识与评估 / 方法理解 / 独立研究决策 → 可观察任务表现**。
- “校园数字学习工具与学习资源使用”只作低专业门槛的任务背景，不研究该主题本身。
- 企业端是补充的需求侧能力画像，用于与学生侧能力表现作结构性对照；不是企业绩效研究或因果模型。
- 企业 taxonomy 需由导师文献、实际岗位文本和人工复核共同形成；当前未取得岗位文本，尚无实证画像。
- 导师文献包可供学习和引用，但每篇是否适用仍须核验；两篇全文无法核验，不用于支持实质结论。
- “信息辨识与评估能力”“独立研究决策能力”是项目工作术语，不宣称为已验证量表名称。
