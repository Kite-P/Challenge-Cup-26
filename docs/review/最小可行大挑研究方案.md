# 最小可行大挑研究方案（条件式）

本方案是 `CONTINGENCY`，不是主动删除已确认的企业补充方向，也不授权实施。

若企业数据暂不可得、外校渠道不成功、专项赛不相关或资源有限，主体社会调查仍可围绕学生端成立：经审批的问卷主样本 + 可行且获批的短任务子样本 + 负担可控的少量学生/教师访谈。若任务或访谈未获准，研究问题与结论范围需相应缩窄，不能仅靠问卷声称观察到客观能力。

企业端在规则允许时可降为公开合法的需求侧背景证据，或暂不纳入实证结果；导师已确认企业方向需作为补充规划，故只有在数据/许可门槛明确不能满足时，才带证据说明限制并走重新确认流程。单校便利样本如无法支持外推，应明确限定场域。

任何最小方案仍须通过本校审批、导师工具审核、渠道许可、知情同意与 DMP 门槛。当前状态 `PILOT_BLOCKED`。
