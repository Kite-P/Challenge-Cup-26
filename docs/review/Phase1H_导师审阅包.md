# Phase 1H 导师审阅包

**用途：**将本轮候选研究设计和报告母稿交导师审阅。该审阅包不是研究申请、伦理材料或执行授权。当前项目门禁继续为 `PILOT_BLOCKED`；没有联系或招募任何真人，没有实施问卷、短任务、访谈或采集数据。

## 一、建议优先审阅的五份材料

1. [问卷 v0.5 导师审阅稿](导师审阅_问卷v0_5.md)：学生研究经历与 AI 协作方式，核心17题组、3个可选题组，约8–12分钟设计估计。
2. [10分钟短科研任务 A v0.5](导师审阅_10分钟短科研任务.md)：三张合成材料卡，观察问题界定、材料评估、方法适配、限制及最终方案。
3. [学生访谈提纲 v0.3](导师审阅_学生访谈提纲.md)：围绕研究过程和本人决定，约20–30分钟未验证估计。
4. [教师访谈提纲 v0.3](导师审阅_教师访谈提纲.md)：收集一般教学观察，不评判具体学生，约20–30分钟未验证估计。
5. [大挑社会调查报告 Master Draft v0.1](../report/大挑社会调查报告_Master_v0_1.md)：第1–4章叙述草稿；后续结果章节只留证据占位。

配套评分锚点、字数预算、章节证据矩阵、预测试方案和论文对照笔记供需要时查阅，均为内部候选。

## 二、主线与范围

主线保持“AI协作方式 → 信息辨识与评估 / 方法理解与适配 / 独立研究决策 → 可观察任务表现”。问卷为学生端主要证据，短任务和学生/教师访谈用于补充。校园数字学习工具与学习资源仅是低专业门槛的中性任务情境，不研究平台实际效果。企业岗位需求仅为 `OPTIONAL/RESERVE`，当前无合法可用岗位文本，不影响学生端主线。

不新增核心构念、心理量表、任务或模型；不预设AI带来正向效果；不把使用方向、文字长度或单次任务结果等同稳定能力。不使用 TAM、MAIN、Q 方法、因果、中介、调节或潜类别作为本轮主线。

## 三、报告与证据现状

Master Draft 的第1–4章可供设计审阅，但文献引文仍须回看原文并核对书目信息。摘要、样本与方法实施细节、问卷结果、任务结果、访谈主题、企业需求侧、讨论和结论均待相应真实证据；不得用模拟流程或预想填充。字数预算是内部规划，正式赛规未确认。

## 四、未确认事项

以下保持原状态，不由本轮文档工作推定解决：`CURRENT_CYCLE_RULES_PENDING`；学校审批公开状态 `OFFICIAL_PROCESS_NOT_FOUND`；BTBU/CUFE渠道 `WAIT_SUPERVISOR_EXTERNAL_CONFIRMATION`；招聘数据 `RECRUITMENT_DATA_NOT_YET_AVAILABLE`；样本框、正式 N、工具冻结、评分者安排、数据关联和报告规范均 `PENDING`。

## 五、请导师确认的四个关键问题

1. 研究核心范围是否仍限定为学生端 AI 协作过程，以及信息辨识与评估、方法理解与适配、独立研究决策和任务内观察，不再增加核心构念？
2. 问卷为主、短任务和学生/教师访谈为补充的证据分工是否合适；约10分钟任务和约20–30分钟访谈的候选负担是否可接受？
3. 科研经历应作为入组门槛还是仅作为背景/分层信息？在未确认前维持 `PENDING`。
4. 当前周期竞赛规则、学校审批/备案责任部门及可用招募渠道应以哪些正式文件或流程确认？在确认前我们不会接触学校或参与者。

**审阅后仍不自动启动研究。**如导师认可候选方向，仍需先完成适用竞赛规则核验、学校审批结论、许可渠道、同意和数据管理要求，之后再由人工决定是否提出下一阶段申请。
