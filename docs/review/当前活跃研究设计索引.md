## 当前研究主线

生成式 AI 协作方式 → 信息辨识与评估能力 / 方法理解与适配 / 独立研究决策能力 → 特定短任务中可观察的作答表现。学生问卷是拟议的主要证据，任务、学生访谈和教师访谈为互补来源；企业岗位文本只作为需求侧补充，且当前不可用。校园数字学习工具与学习资源只是低专业门槛的中性任务情境，不是研究主题。
