# Blueprint v0.3 冻结条件

Blueprint 不是文字写完即冻结。正式候选版本至少须解决：

1. 当前周期适用竞赛规则、作品类别、团队资格及校内流程；
2. 机构对问卷、访谈、任务及跨校/课程实施的审批责任与流程；
3. 主要样本范围、可用样本框、学校覆盖、招募许可和样本量决策依据；
4. 问卷、短任务、评分、访谈的结构/负担/数据链接规则；
5. 企业需求侧数据角色、来源版本、许可与最小字段；
6. 主分析、缺失、聚类、多重比较、任务评分一致性和解释边界；
7. DMP、安全、退出、保留期限和销毁处置；
8. 导师对明确版本的审阅记录。

未解决事项须为 `PENDING` 并标出触发条件；竞赛规则未定、审批不明、工具未审或总体/渠道不可行时，维持 candidate。真人 pilot 另需完整批准，不由 Blueprint 冻结自动触发。
