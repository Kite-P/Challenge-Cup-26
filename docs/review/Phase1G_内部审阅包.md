## 1. 方向与候选标题

大挑主体赛方向已由导师确认；作品类别按哲学社会科学类社会调查报告候选准备。可考虑标题：“生成式AI协作与财经相关本科生研究型学习：信息辨识、方法适配与独立决策调查”。标题仍是内部候选，不代表正式规则或导师定稿。

## 2. 研究问题与主线

拟了解财经相关本科生在研究型学习任务中如何与生成式 AI 协作，并描述其与信息辨识与评估能力、方法理解与适配、独立研究决策能力以及可观察任务表现之间的关系。正、负、无、非线性或异质结果均允许；不预设因果。

校园数字学习工具与学习资源使用是低专业门槛中性任务情境，不是研究主题。核心结构保持简洁：AI 协作方式 → 三个研究判断/方法维度 → 特定任务表现；不另加心理构念，不建未经验证的总量表。

## 3. 证据与样本架构

学生问卷为 PRIMARY 候选；短任务、学生访谈、教师访谈为互补来源。企业岗位需求画像为已确认的补充方向，但数据源/许可未落实，不可取代学生调研。目标总体候选为普通高校财经相关专业在读本科生；教育部专业目录只作为专业分类参照，不是样本框。学校数、专业边界、抽样渠道和 N 均 PENDING。科研经历三类只用于描述/分层，不作为能力标签或硬门槛。

## 4. 工具与分析

问卷 v0.4、短任务 A v0.4、评分和访谈提纲均为审阅候选、未试测。评分 v0.4 的重复计分和合理采纳 AI 误罚问题经三重桌面审阅后形成 v0.5 五维候选；未获导师审阅。核心疑虑包括自报不等于行为、单任务不能外推总体能力、评分分项边界需要继续校准。
