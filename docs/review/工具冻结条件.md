# 工具冻结条件

工具由候选转为 v1.0 必须逐件满足：

- 导师已对对应工具版本作可追溯审阅；
- 机构已明确适用审批/备案要求且全部完成；若判定无需某项审批，须有正式可核依据；
- 目标总体、招募渠道、使用者资格、同意、退出和数据管理能够匹配；
- 构念、题项/任务要求、变量注册表、缺失码和分析映射一致；
- 问卷跳题、任务材料来源/许可、评分维度重叠与评分员说明静态审计通过；
- 如需真人认知访谈/可行性 pilot，须先获独立批准，不能由“工具冻结”自动授权；
- 数据最小化、存储访问、保存期限与销毁要求均获机构确认。

当前以上条件未全部满足。不得仅因文件齐全或模拟测试通过就把问卷、任务、访谈提纲冻结为 v1.0。
