# 项目边界

## Challenge-Cup-26

本仓库只承载当前挑战杯教育/学生调查方向：财经类本科生在研究型学习任务中与生成式 AI 协作的方式、相关判断和任务表现，以及经批准后可能形成的调查报告。

## 未来申研规范实证论文

导师提到的、未来用于研究生申请的规范实证论文是独立任务；选题和设计尚待导师另行提供。启动时应另建项目目录和 Git 仓库，单独确定数据权限、研究设计和时间表。不得把企业实证分析、企业数据或其代码/结果混入 Challenge-Cup-26，也不得将本项目的候选设计误作该论文的批准方案。

## 当前边界

当前 Phase 1A 仅开展文献梳理和研究工具草拟。没有正式招募、调查、访谈、行为任务实施或企业数据分析。任何后续采集都须先满足本项目审批、导师确认、招募渠道、知情同意和数据管理条件。
