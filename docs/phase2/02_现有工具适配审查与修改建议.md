# 现有工具适配审查与修改建议

**范围：**问卷 v0.5、短任务 A/评分 v0.5、学生/教师访谈 v0.3。仅提修改建议，不重写工具、不冻结版本、不实施真人调查。整体判断：工具与研究问题大体匹配，但当前问卷对“培养需求”和可分组总体特征测量不足；短任务可继续作为辅助证据；访谈需要强化对实际行为、反例和支持需求的追问。

## 一、问卷 v0.5：逐题建议

| 题号 | 当前作用与适配判断 | 建议（不在本轮改写原工具） | 原因/优先级 |
|---|---|---|---|
| Q1 | 研究经历筛选，跳题支点；适配 | 保持非入组门槛；确认“研究型学习任务”定义示例足以区分普通课程作业 | 避免将无科研经历者排除成能力较弱；P1 |
| Q2 | 最近任务类型；适配但带旧赛事名 | 将选项中的“挑战杯”改为中性“学术科技竞赛中的研究任务”，必要时拆分课程项目/竞赛/导师项目；保留不知道和拒答 | 赛事转向后不应把旧目标写入现行问卷；P0 |
| Q3 | 任务参与环节；适配 | 评审是否需区分“实际负责”与“仅参与”；避免重复记录过多细节 | 有助于研究经历分层，但不能用选项数作能力分；P1 |
| Q4 | 专业大类；适配不足以支撑精细分层 | 在不收集学校/院系身份的前提下，增加最低必要的专业细类或专业代码映射选项，并单独处理边界专业/不愿回答 | 宽泛类别无法复核“财经相关专业”纳入边界；小单元需抑制；P0 |
| Q5 | 年级；适配 | 保留；与学制差异、非传统年级状态的处理由团队决定 | 年级是必要分层描述；P1 |
| Q6 | 方法/资料/数据训练经历；适配 | 维持现有互斥和不熟悉选项；若问卷负担允许，可区分“课程学习”与“实际练习”已有类别，不新增总分 | 解释训练暴露，不是能力测验；P1 |
| Q7 | 最近任务中是否使用 AI；适配 | 保留“无可用工具/无适用环节/不确定/拒答”不同路径；最终核对跳题和问卷平台编码 | 避免把环境受限误成主动不用；P0 |
| Q8 | 六类 AI 使用环节；核心适配 | 保留六类；若要描述行为强弱，考虑仅增加少量明确时间范围/频次口径，不把六项相加为能力分 | 当前可回答“环节”，未测频次/深度；符合主线但不能宣称全过程覆盖；P1 |
| Q9 | 是否要求 AI 解释依据/条件；适配 | 明确只回想最近任务，并避免将追问次数作为能力代理 | 使用行为可以描述，但单题存在回忆误差；P1 |
| Q10 | 最常用核查方式；核心但信息偏窄 | 优先问是否实际核查，再记录最常用方式；区分核对“来源存在”与“来源支持具体主张” | “最常用方式”会遗漏未核查频率/多种方式；P0 |
| Q11 | AI 输出处理；适配 | 保留照用、核查后采用、修改/部分采用、参考、不采纳等中性选项；标明“未遇到”与缺失不同 | 能描述行为，不按采纳方向评分；P1 |
| Q12 | 分歧处理；适配 | 保留“未遇到分歧”选项；可考虑把“继续问 AI”与“最后由本人决定”分成两层 | 行为路径与最终决策权不是同一件事；P1 |
| Q13 | 一般资料判断的第一关注点；适配有限 | 考虑多选少量实际核查维度，或补“最近一次实际如何核查”而不是仅问最先关注；保留无经历/未知 | 单选第一关注点不能描述完整信息评价过程；P0 |
| Q14 | 是否让 AI 比较方法；无法单独证明本人方法理解 | 增加/改为一个本人方法适配行为指标（例如是否考虑备选方法及选择依据）；未涉及方法选择单列 | 目前把“让 AI 比较”当作方法理解代理不成立；P0 |
| Q15 | 未核查即照用的回顾；敏感且易社会称许偏差 | 采用更中性、明确的最近任务时间框，确保有“未遇到输出/记不清/拒答”；不把该题当诚信或能力标签 | 降低道德化作答和回忆偏差；P1 |
| Q16 | 最近任务最有帮助的支持；不足以回答培养需求 | 保留“获得过何种支持”用途；新增或替换一个简短“最希望获得哪类训练/指导”题，类别限于信息评估、方法适配、AI核验、独立决策等 | 已获支持不等于当前需求；这是形成培养需求画像的关键缺口；P0 |
| Q17（OPTIONAL） | 对课程 AI 规则的认知；有用 | 可保留为选答题，明确测的是“受访者知晓情况”，不是课程实际政策审计 | 有助解释使用差异；选答不新增主线构念；P2 |
| Q18 | 中性资料口径情境；与任务内容部分重复 | 保留为低成本情境理解项或与短任务去重；不计分、不当作稳定能力 | 避免问卷过长和同一能力重复测量；P2 |
| Q19（OPTIONAL） | AI 风险开放回答；有用但编码成本较高 | 维持 optional，规定不填个人/校内可识别信息，并预先明确编码与引用边界 | 不能从少量开放回答估计普遍比例；P2 |
| Q20（OPTIONAL） | 信息判断自我把握；适配为自我感知 | 与 Q13/Q18/任务分数分开呈现；不称实际能力 | 自我效能/把握感不等同表现；P2 |

**建议优先顺序：**先处理 Q2、Q4、Q10、Q13、Q14、Q16；再做其他轻量澄清。所有建议都须人工审阅、同步跳题表/字典/分析映射并重新静态审查；本轮不更新问卷版本。

## 二、短任务 A v0.5 与评分 v0.5

**是否保留：是，作为辅助行为观察证据，值得保留。**它以合成材料、固定问题和约10分钟设计估计观察资料判断、问题界定、方法适配、结论边界和最终研究决策，能补足问卷自报；不会替代主体问卷，也不研究校园资源满意度。

| 审查点 | 判断与建议 |
|---|---|
| 与研究问题一致性 | 高；任务行为与核心研究链匹配。保持五维分项，不增加能力构念、不合成总分。 |
| 公平性 | 保持材料自足、避免财经或特定校园知识；说明可用或不用 AI 均可，不因采纳/拒绝方向计分。 |
| 10分钟可行性 | 目前只是8–12分钟设计估计，未测。先桌面检查阅读量、手机可读性和作答负担；真人计时须待审批授权。 |
| 赛事 AI 合规 | 第十七届规则未核实前，不确定未来正式参赛材料或调查方案可使用 AI 到何种程度；参与者任务的 AI 使用条件也须单独审批。不得把“研究 AI”作为规避赛事规则的理由。 |
| 分析用途 | 报告五维分布、不可评分比例和评分质量；如获批且取得明确同意，才讨论随机编码链接问卷。未链接时不作个人级问卷—任务关联。 |
| 评分质量 | 五维锚点、双评比例、仲裁和一致性方法都未验证；保留 `NOT_SCORABLE` 与0分区别。不能将合成评分表现当作信度证据。 |

## 三、学生与教师访谈 v0.3

| 工具 | 适配判断 | 修改建议 |
|---|---|---|
| 学生访谈 | 与问卷、任务的过程解释功能一致；涵盖问题界定、来源判断、方法、限制、AI协作、最终决定、支持与困难 | 以最近一次具体研究经历为主线，要求过程顺序和反例；减少抽象“能力好不好”提问；补问“最需要何种训练”及未使用 AI 的条件；不索取提示词、聊天记录、作业原件。 |
| 教师访谈 | 可补教学观察，但不能代替学生行为或企业数据 | 询问观察到的可见行为、教学支持、相反案例和不确定性；不问可识别学生/课程细节，不请教师替学生评能力或替企业讲岗位需求。 |
| 两份共同边界 | 20–30分钟均为未验证估计；未审批、未联系 | 先缩减冗余主问题并匹配研究问题；获批后再确定样本、录音、转录、引用、停止规则和是否与问卷/任务链接。访谈不用于总体比例。 |

## 四、结论

现有工具无需整体推倒重来。当前最大方法缺口是问卷未直接测培养需求、专业/总体分组的复核信息不足、部分自报题不能代表实际能力；这些在正式冻结前优先处理。所有修改建议暂为 `PENDING_SUPERVISOR_REVIEW`，没有任何工具可据此实施。
