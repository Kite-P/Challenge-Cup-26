# 问卷数据质量与排除规则候选

状态：`PENDING_APPROVAL`；没有真人响应、完成时间分布或可校准阈值。

## 预先分类的质量信号

- 重复提交：优先依赖经批准、非识别性平台响应ID；结合一致性逻辑复核，不用 IP/设备指纹默认去重。
- 明显逻辑矛盾：按问卷跳题与事实约束定义，保留原始记录并标记待审，不自动删除。
- 极短完成时间：只有未来获批试测获得合理时长分布并经预先审阅后才可能设置阈值；当前不得定义“小于 X 分钟自动剔除”。
- 大量漏答：区分结构跳题、拒答、不适用与普通漏答；按分析所需变量处理，不直接整行剔除。
- 批量/机器人迹象：只使用审批允许且可解释的证据；不启用隐形指纹、IP或外部画像。
- 无效开放题：依据预先制定的可编码规则标记，如空白、与题意无关或纯粹重复字符；保存审计理由，不因观点不同判为无效。

## 决策流程

建立标记 → 双人复核争议记录 → 按冻结规则决定纳入/排除 → 记录计数及理由 → 报告敏感性分析。不得看到结果后改阈值或以提升显著性为目的排除。
