## 经历分类维度

经历按类型分别记录，可多选；每类再记录深度、角色、持续时间、实际投入/具体任务，不压成单一科研经历分数。

| 类型 | 例子（非排他） |
|---|---|
| 课程论文/课程研究项目 | 课程论文、课程调查或课程研究设计 |
| 大学生创新创业训练计划（大创） | 主持/参与国家级、省级、校级或院级项目；级别另记 |
| 挑战杯/学术科技竞赛 | 研究、调研或学术科技类参赛项目；与策划类区分 |
| 跟随导师科研 | 在导师课题中承担资料、设计、数据、分析或写作工作 |
| 社会调查 | 问卷、访谈、田野或社会实践中的调查研究 |
| 科研助理 | 作为科研助理承担的项目工作及实际职责 |
| 学术论文/会议 | 论文、会议报告或展示；单独记录个人贡献 |
| 其他研究型项目 | 不能归入以上类型的项目，简要说明任务类别 |

## 建议记录字段

经历类型；是否实际参与；任务内容；个人角色；在选题、文献、研究设计、数据、分析、写作六阶段的实际参与；决策/执行责任；开始与结束时间或持续周数；投入频率/时长区间；是否有导师指导；产出类型；自报熟悉度。选项和回忆窗口尚待设计审阅，不要求上传证明或披露敏感材料。
