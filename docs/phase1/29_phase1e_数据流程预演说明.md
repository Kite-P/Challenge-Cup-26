# Phase 1E：数据结构与分析流程预演

**状态：**内部模拟流程检查完成；真人试测、问卷、访谈、任务实施与数据采集仍为 `PILOT_BLOCKED`。

## 目的与范围

本阶段使用固定种子人工构造的数据，不是为了提前得到结果，而是检查“研究设计→数据字段→整理校验→分层描述→结果表图→挑战杯报告”的工程链条能否执行，以及哪些边界容易被误用。学生端仍为主线：问卷是主要证据，短任务及学生/教师访谈为补充；招聘岗位画像仅是补充需求侧证据。

本轮未接触真人、真实公司或真实招聘文本；未联系导师、学校或参与者；未发问卷、试测、访谈、运行Stata或下载任何数据。没有冻结研究工具或正式样本量。模拟行数只服务软件测试。

## 重现

固定种子为 `20261004`。在已具备 pandas、matplotlib 的环境运行：

```powershell
python -m src.run_phase1e_synthetic_pipeline
python -m unittest tests.test_synthetic_pipeline -v
```

生成器只写 `data/synthetic/`，流水线汇总写入 `results/synthetic/`。不删除目录，不读取其他项目。所有模拟CSV均有 `synthetic_flag=TRUE`，并由 README 和结果说明重复标注。

## 使用边界

**任何 Phase 1E 模拟输出不得作为挑战杯实证结论、论文发现或真实企业需求引用。**不得把模拟分布解释成理论支持、显著性、效果大小或样本量建议。模拟数据只说明字段、连接、编码、代码输出和审核机制可运作；不说明测量效度、现实可行性或研究问题已被回答。

去标识化研究编号 `research_id` 可用于获批后的记录连接，但去标识化不等于完全匿名；当前不存在真实编号和身份映射表。未使用AI者不进入AI协作过程分析，也不编码为低AI能力或0分。
