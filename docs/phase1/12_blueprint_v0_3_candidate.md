4. 主要成果为挑战杯调查报告；质量合适时，未来可尝试改写教育学方向论文。
5. 首都经济贸易大学、北京工商大学、中央财经大学均作为候选学校列出，外校尚未授权。
6. 增加行为任务表现，与问卷自评及访谈形成不同来源，不预设它们一致。

## 候选核心问题

在财经类高校及其他高校财经相关专业本科生的研究型学习任务中，学生如何与生成式AI协作；不同协作方式与信息评价、方法理解、独立研究判断和可观察任务表现之间呈现何种关系？正、负、无关系、非线性和异质性结果均可能；不作因果预设。

## 候选协作框架

描述AI协作阶段、交互深度、输出处理、决策权和对建议的理解。先报告维度，不合成为未经验证的“AI协作总量表”。观察结果区分自评、任务表现与访谈解释。

## 候选证据与流程

聚焦文献 → 工具审阅/审批路线确认 → 获批后才考虑问卷、访谈和短任务 → 评分者校准/质量评估 → 描述、测量、评分一致性和关联分析 → 按实际证据提出训练建议。Phase 1A只完成草案与流程调查，不实施其中的数据收集步骤。
