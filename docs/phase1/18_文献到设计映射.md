# 文献到设计映射

| 文献/来源 | 支持的设计环节 | 设计决定 | 保留的限制 |
|---|---|---|---|
| M01、M05、M10；本科生科研参与/培养研究 | 研究问题、经历变量 | 区分课程、科研项目、竞赛、导师课题等经历，并记录角色/深度 | 特定学科/学校研究不能确定本项目入组阈值；D05 `PENDING` |
| M04、M09、M23 | 研究问题、AI协作变量、任务阶段 | 问卷区分任务环节；任务关注问题、信息、方法、限制 | 教学案例不是本项目效果证据；无直接依据证明哪种使用方式最好 |
| M13、M18 | 问卷行为变量、研究问题 | 不只问有无使用；记录阶段、来源核验、采纳与修订；允许非线性关联 | 自报/横截面关联不等于因果；不能移植其总量表结论 |
| M14、M24 | AI使用类型、经历/差异描述 | 描述使用深度和模式，避免简单二分 | 类型依样本与测量而变，不直接复制画像/潜类别 |
| M11、M03、M05 | 教师指导/学习环境变量、教师访谈 | 保留少量指导背景与教师访谈作为补充 | 特定情境；不建立指导效果因果模型 |
| M12、M20 | 财经/会计教育背景、竞赛叙事 | 说明财经邻近教育情境可关注AI与评价/技能培养 | 会计评估不能代表跨专业研究设计；不支持本项目竞赛结论 |
| M17及认知发展理论文献 | 假设边界、分析计划 | 对正、负、零及异质结果均开放 | 元分析平均效应和理论论述均不能预测本样本效应 |
| 既有 EVON、GLAT、epistemic judgment 文献；导师包未提供直接同构量表 | 信息辨识与评估操作化 | 短任务评相关性、来源、依据、支持度、交叉核验与过度推断 | 题项/许可不直接复制；导师包对此具体操作化的直接支持有限 |
| 导师包无直接“自评—本项目任务表现”验证 | 学生问卷与任务表现 | 两类证据分开报告，不构造能力差值 | 是否个人级关联须获审批；这是研究空白 |
| 内部设计逻辑（无直接文献支持） | 中性情境、3 卡压缩、约 12 分钟任务 | 减少专业门槛和负担 | 设计假设未试测，`NOT PILOTED` |
| 当前没有岗位语料；导师材料不是招聘文本 | 企业需求画像与学生对照 | 后续获授权后再建立 taxonomy，映射标签 `DIRECT` / `PARTIAL` / `NO_DIRECT_MATCH` | 目前没有直接支持具体企业需求维度的岗位证据；不计算 Gap Score |
| 挑战杯叙事 | 作品报告结构 | 以学生问卷主线为核心，企业画像为补充，按数据实际结果提出训练建议 | 文献不能确认赛道、校级资格或本项目发现；D09赛道仍 `PENDING` |

本映射只说明设计选择的参考来源，不构成因果模型、量表效度证据或导师/学校批准。文献详见 `14_导师文献证据地图.md` 与 `references/导师参考文献目录.md`。
