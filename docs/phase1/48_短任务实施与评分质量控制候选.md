# 短任务实施与评分质量控制候选

状态：`PENDING_APPROVAL`；无真实任务实施。

## 状态编码

候选状态：`NOT_STARTED`、`IN_PROGRESS`、`COMPLETE`、`PARTIAL`、`ABORTED`；每个维度另记 `SCORABLE` 或 `NOT_OBSERVABLE`。中断/未完成不视为能力低。

## 异常情形

记录超时、参与者退出、AI 服务故障、无法访问 AI、参与者选择不用 AI、网络/设备中断及其他技术问题。按批准方案提供一致的替代路径；不得临场改变任务条件后仍合并为同一暴露组。

## 评分质量

评分者仅见研究编号与去身份化作答；不见姓名、学校、AI 使用态度问卷等无关信息。双评比例、随机抽取方式、复评和仲裁比例为 `PENDING`，待样本与资源确定后预先冻结。评分员先完成合成材料训练；合成一致性仅检查代码流程，不是量规信度证据。保留原评分、复核理由及最终状态。
