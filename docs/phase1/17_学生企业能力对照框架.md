# 学生—企业能力对照框架（候选）

**状态：**仅概念映射；岗位文本未取得，学生数据也未采集。禁止据此宣称存在人才供需缺口。

三层结构：**Level A** 为企业岗位文本中的能力需求；**Level B** 为学生问卷/任务中的可观察指标；**Level C** 为两侧证据的可比性判定（`DIRECT`、`PARTIAL`、`NO_DIRECT_MATCH`）。表中一行表示待核验的候选映射，不表示两侧已经等值。

| 学生侧证据 | 企业侧可能证据 | 允许的关系标签 | 解释边界 |
|---|---|---|---|
| 问卷自报的资料判断行为 | 岗位职责中明确的信息查找/核验要求 | `DIRECT` / `PARTIAL` / `NO_DIRECT_MATCH` | 自报态度与岗位要求不是同一测量 |
| 任务中信息辨识与评估表现 | 对信息质量、来源、证据判断的职责要求 | `DIRECT` / `PARTIAL` / `NO_DIRECT_MATCH` | 任务分数不能代表岗位实际绩效 |
| 方法理解与问题界定表现 | 数据分析、业务研究、问题解决要求 | `DIRECT` / `PARTIAL` / `NO_DIRECT_MATCH` | 词语相似不等于方法能力等价 |
| 独立研究决策表现 | 独立判断、方案选择、责任承担要求 | `DIRECT` / `PARTIAL` / `NO_DIRECT_MATCH` | 招聘措辞通常不揭示真实工作自主权 |
| AI协作过程及输出核验 | 岗位文本明确的数字/AI工具使用要求 | `DIRECT` / `PARTIAL` / `NO_DIRECT_MATCH` | 未提及 AI 不能推断岗位不需要 AI |

映射须双侧给出操作定义、正反例和来源段落；部分对应保留为部分，不为了形成整齐矩阵而强行配对。`NO_DIRECT_MATCH` 表示证据材料没有可直接比对项，不表示能力无价值。
