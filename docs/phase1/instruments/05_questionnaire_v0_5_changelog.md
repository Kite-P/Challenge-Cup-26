# 问卷 v0.4 → v0.5 修订记录

**状态：**问卷 v0.5 为导师审阅候选，未试测、未批准分发。此记录解释设计修订，不代表题项有效性已验证。

| 修订 | 原有问题/导师要求 | v0.5处理 | 依据 |
|---|---|---|---|
| 完整题干和选项 | v0.4虽列出题组，但若干选项、正式引导语和跳题仍较概括 | 补齐参与者可读说明、Q1–Q20、选项、开放回答、适用范围与路径 | 导师要求“把问卷问题列好”；论文2附录A（PDF pp.59–66）提供问卷从说明、筛选到结束的结构参考 |
| 回顾窗口 | v0.4提出最近一次任务，但不同题组的适用条件尚不完全一致 | 统一为过去12个月最近一项研究型学习任务，并把无任务/不确定作为真实路径 | Phase 1G审计；论文2筛选题和论文3筛选逻辑提供结构参考 |
| 题组负担 | v0.4核心15组及可选自我感知题，完整答题选项仍需具体化 | 组织为17个核心题组和3个OPTIONAL题组，设计估计8–12分钟；待导师审阅及未来认知测试验证 | 导师本轮要求；论文1正式问卷、论文2问卷结构、论文3前测—修订流程，仅作组织参考 |
| 自报与表现区分 | 避免自评题被误读为能力测验 | 明确Q13为资料判断自报，Q17与Q19–Q20为OPTIONAL，Q20标为`SELF_PERCEPTION`；Q18仅为情境选择，仍不替代独立短任务 | Phase 1G结果边界；三篇论文工具与方法对照 |
| 跳题与缺失 | `未使用`、`未遇到`、`不适用`和未答不应混为一类 | 明确Q1、Q7路径；列出拟用`NA_SKIP`、`NA_APPL`、`NA_DK`、`NA_REFUSE`、`NA_MISS`，并说明尚未冻结 | 论文2附录A的筛选/跳题结构；论文3前测问卷筛选题；既有v0.4跳题审计 |
| 研究场景与题项边界 | 校园数字学习工具仅作中性测量情境，研究主题仍是财经本科生的AI协作与研究决策 | 保留一题简短校园资源情境，不增加新的专业知识模块或效果假设 | 导师此前确认的中性场景；短任务与问卷分工 |
| 不移植论文构念 | 不能把项目改成MTI动机、TAM接受度或健康信息采纳 | 不引入TAM、MAIN、Q排序、AI信任总量表或中介/调节题组 | 三篇论文研究对象和理论框架均不同；导师明确要求方法借鉴而非机械复制 |

**本轮未做：**未招募、发放、试填、认知访谈或任何数据收集；未计算信度/效度；未冻结样本量、学校、正式数据说明或实施权限。具体差异以 [`05_questionnaire_v0_5_supervisor_review.md`](05_questionnaire_v0_5_supervisor_review.md) 为准。
