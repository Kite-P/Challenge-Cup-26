# HISTORICAL｜问卷严格跳题树 v0.4（内部复核）

当前候选路径见 [`08_questionnaire_skip_tree_v0_5_candidate.md`](08_questionnaire_skip_tree_v0_5_candidate.md)。

本文件按现有问卷 v0.4 审阅稿定义模拟与校验口径，不修改真人工具，也不授权实施。

| 代码 | 语义 |
|---|---|
| `NA_SKIP` | 题目未展示 |
| `NA_APPL` | 题目展示，但情形不适用 |
| `NA_DK` | 题目展示，受访者不知道/记不清 |
| `NA_MISS` | 题目展示但留空 |
| `NA_REFUSE` | 题目展示且明确拒答 |

## 路径

1. 无符合定义的近期研究任务：AI使用回顾、阶段和任务细节项目均未展示，记 `NA_SKIP`；一般信息评价情境、经历/训练和背景题仍可回答。
2. 有近期任务且 A1=NO：A2阶段项已展示，选择固定项 `NOT_USED`；A3–A7与A15等使用细节跳过为 `NA_SKIP`。
3. A1=UNSURE：A2已展示，允许 `NA_DK`；因是否使用未确认，详细协作题跳过为 `NA_SKIP`。
4. A1=YES：阶段/细节题展示，可记不知道或留空。若AI未给相关输出，使用固定项 `NO_RELEVANT_OUTPUT`；若任务没有方法选择，`NO_METHOD_CHOICE`。这两者是已展示题的实质选项，不是跳题码。
5. 无研究经历：经历深度题未展示，记 `NA_SKIP`；一般方法训练题仍可答。

这些规则只用于合成数据契约及单元测试。真实受访者路径须在获批工具与平台逻辑确认后再审。
