# 研究型学习中的生成式 AI 协作问卷 v0.3（候选）

**状态：**草案，未获批准，未做认知访谈、试测或效度检验；目标 10–15 分钟未实测。仅为候选题目，不得分发。题目为原创工作表述，不复制成熟量表。

## 题目组织与变量类型

回顾窗口暂拟“最近一次研究型学习任务”；无经历者跳过相关题目待审。行为频率项可用“从未/偶尔/有时/经常/不记得或不适用”。不得将不同变量类型合成为总分。

| 编号 | 层级/变量类型 | 候选题目 | 用途 |
|---|---|---|---|
| A1 | CORE / AI使用事实 | 最近一次任务是否使用生成式 AI？是/否/不确定 | 描述使用状态 |
| A2 | CORE / 阶段行为 | 使用在哪些阶段？界定问题/判断材料/选择方法/考虑限制/未使用/不记得（多选） | 描述协作阶段 |
| A3 | CORE / 协作行为 | 是否要求 AI 说明理由或适用条件？是/否/不记得/未使用 AI | 理由追问 |
| A4 | CORE / 信息评价行为 | AI提供事实或来源时，是否检查来源可找到、内容是否支持说法？未要求/要求但未核/核查可找到/核查内容支持/无相关输出/不记得 | 区分索要来源与核验 |
| A5 | CORE / 输出处理行为 | 对建议通常如何处理？基本采纳/修改后采用/仅参考部分/不采用/未使用 AI/不记得 | 描述采纳而非价值评价 |
| A6 | CORE / 决策行为 | AI建议与你想法不同时，通常如何处理？直接采用/保留原想法/比较依据后决定/继续追问/未遇到/不记得 | 描述判断过程 |
| A7 | CORE / 方法理解行为 | 是否要求 AI 比较方法各自能回答什么问题及限制？是/否/不记得/未使用 AI | 方法比较行为 |
| A8 | CORE / 自报信息评价 | 判断拟采用的信息时会看什么？相关性/来源/依据/其他信息印证/未检查/不记得（多选） | 自报行为，不是能力测验 |
| A9 | CORE / 情境判断 | 情境：“页面访问次数上升，说明学习效果提高。”你会先做什么？直接采用/查指标定义与来源/找其他解释或对照/暂不下结论并说明缺失证据/其他 | 情境化判断，需审阅 |
| A10 | CORE / 经历类别 | 过去 12 个月做过哪些研究活动？课程论文/课程研究、大创、挑战杯或学术科技竞赛、导师课题、社会调查、科研助理、学术论文/会议、其他研究型项目、没有（多选） | 经历类型，不等同能力 |
| A11 | CORE / 经历深度 | 对最相关一项经历，你在选题、文献、设计、数据、分析、写作中的实际参与情况、角色、持续时间和投入如何？分项短选项待审 | 描述参与深度 |
| A12 | CORE / 经历背景 | 是否接受研究方法或信息评价课程/训练？无/课程/工作坊或讲座/自学/其他/不记得（多选） | 背景描述 |
| A13 | CORE / 基本样本特征 | 专业大类、年级、学校类型（财经类/综合或其他）等最少必要类别；具体字段与可识别风险待审批 | 样本描述；不收姓名学号 |
| A14 | CORE / 教师指导与学习环境 | 最近相关任务是否获得方法指导或反馈？无/课程教师/导师或项目负责人/同伴/其他；帮助程度可选简短类别 | 学习环境背景，不自动作为因果变量 |
| A15 | CORE / 风险行为 | 是否曾在未核验依据时基本照收 AI 的事实、来源或建议？从未/偶尔/有时/经常/不记得/未使用 AI | 过度采纳行为自报，不贴个人标签 |
| A16 | CORE / 能力自评 | 你对自己辨认资料来源、判断主张依据的把握程度如何？简短 5 点自评/不适用 | 自评能力，与行为及表现分开 |
| A17 | CORE / 态度 | “即使 AI 给出答案，最终核查和决定仍是研究者的责任。”5 点同意度/不确定 | 单项责任态度，不与行为混计 |
| A18 | OPTIONAL / 行为 | 是否指出 AI 输出的具体问题并要求修正？是/否/不记得/未使用 AI | 可删减 |
| A19 | OPTIONAL / 行为 | 时间有限时是否优先核查可能改变结论的关键信息？总是/有时/从不/不记得/不适用 | 可删减 |
| A20 | RESERVE | 成熟 AI 素养工具或实验条件题 | 本轮不展示、不计入，不复制题目；许可与改编状态 `UNKNOWN` | 仅留审查占位 |
