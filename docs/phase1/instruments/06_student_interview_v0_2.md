# 学生半结构访谈提纲 v0.2

**草案——未经批准，尚未实施。**目标20–30分钟，未实测。仅在审批、知情同意和招募许可全部明确后使用。开场说明无标准答案，可跳过任何问题；不索要个人账号、完整聊天历史或可识别课程/教师信息。访谈围绕AI协作方式、信息评价/方法理解/独立判断，不作为额外构念开发。

| 主题/主问题 | 中性追问（按需，不必全部提问） |
|---|---|
| Warm-up：能否介绍一次最近的研究型学习任务（不说课程/教师姓名）？ | 任务大致要求什么？当时最先做了什么？ |
| 最近一次任务的研究经历 | 哪一步最花时间？你如何决定下一步？ |
| 哪些环节用了或没用AI？ | 是自己决定的还是任务规则要求？当时目标是什么？ |
| 你具体如何与AI互动？ | 是否追问理由、来源或替代方案？能回忆一个不含私人信息的例子吗？ |
| 什么时候会采用AI建议？ | 你当时看了哪些依据？有没有仍不确定的地方？ |
| 什么时候不会采用或会修改？ | 是什么信息让你改变或保留判断？ |
| 你怎样判断资料是否相关、来源是否可用？ | 会看来源、依据或其他材料吗？具体如何做？ |
| 你怎样判断一种研究方法是否适合？ | 你会考虑它能回答什么、不能回答什么吗？ |
| 是否遇到过AI输出不准确或不适用？ | 当时如何发现？后来怎么处理？没有遇到也可以说明。 |
| AI建议与你原想法冲突时通常怎样处理？ | 是否比较过方案？最后由谁作决定？为何？ |
| 教师/课程如何指导AI使用或研究判断？ | 哪类规则或反馈对你有帮助？哪些仍不清楚？ |
| 使用AI后，你的研究做法有没有变化？ | 有哪些具体变化或没有变化？不预设方向。 |
| 学校最需要提供什么研究训练支持？ | 对信息评价或方法选择而言，哪种支持较有用？ |

结束时询问是否有遗漏的相关经验，不追问隐私。是否录音必须有单独选择和单独同意；拒绝录音时是否可做笔记及笔记保存办法 `PENDING`。学生访谈样本与问卷/任务是否连接 `PENDING`。
