# 问卷题组—研究问题—分析映射（v0.4候选）

| 题组 | 为什么保留 | 对应RQ | 候选用途 | 若不使用的删题判断 |
|---|---|---|---|---|
| A1–A2 | 描述使用与阶段，不将频次单独当解释 | RQ1/RQ2 | 使用率和阶段分布 | 若无法明确回顾窗口，先修题干，不应保留模糊行为 |
| A3–A7 | 分别覆盖追问、核查、处理、分歧决策、方法协作 | RQ1/RQ2 | 分项描述/协作模式交叉表 | 任一题无独立用途或与另一题重叠，可删并记录损失，不建立总分 |
| A8 | 观察自报的信息判断策略 | RQ2 | 行为自报描述 | 若与A9或任务重复过多，优先移为OPTIONAL |
| A9 | 多选处理+先做一步+一句理由，避免单一正确答案 | RQ2 | 情境判断策略描述/简短主题归类 | 若无法建立清晰编码规则或负担过高，删理由文本而保留选择结构 |
| A10–A11 | 记录经历类型与真实参与，不用正式项目身份替代实际投入 | RQ3 | 经历分层/背景描述 | 若选项过多，合并罕见类别而不损失主要经历区别 |
| A12 | 表征相关训练背景 | RQ3 | 样本描述/探索分层 | 样本负担不足以支持时移到OPTIONAL |
| A13 | 描述最少必要样本特征 | 全部RQ | 样本结构及有限分层 | 若识别风险过高，删除细粒度类别；不能为分析便利收集可识别字段 |
| A14 | 描述指导环境，避免把关联说成指导效果 | RQ2/RQ3 | 背景描述 | 若无具体分析计划或风险大，移到OPTIONAL |
| A15 | 记录未核验采纳的自报行为 | RQ1/RQ2 | 风险行为分布 | 若与A4/A5冗余或措辞引发污名，删除/改写 |
| A16（OPTIONAL） | 与任务表现区分的有限自我感知 | RQ2 | 仅作自我感知描述；可不纳入 | 若造成能力量表误解或增加负担，直接删除 |

## 预定分析边界

- 以样本与经历描述、AI行为分布、策略自报与情境选择为主；复杂量表、潜类别、因果模型不在当前候选主线。
- A8/A9/A16各自含义不同，不能求均值合成“信息评价能力”；A16为OPTIONAL。
- 未使用AI者仍可进入总体样本描述、A8/A9及经历/背景分析；其AI交互细节为结构性跳题。
- 分析映射是保留理由，不代表本轮删改了旧问卷题。问卷v0.3保留为历史候选；本v0.4只提供新的精简审阅版本。
