# 短任务静态演练（合成作答）

**醒目标识：`SYNTHETIC EXAMPLE`。**以下答案由文本构造，只用于桌面检查题目是否产生不同作答、评分锚点是否可区分，以及有无明显唯一答案暗示。不是真人试测、认知访谈、预测试或参与者数据；不得用于估计时长、难度、信效度或效果。

评分依据见 [`11_short_task_scoring_v0_4.md`](11_short_task_scoring_v0_4.md)。分数只是对下列合成文字按候选锚点演示。

## 合成作答甲（较弱示例）

“我想知道这个平台好不好。用问卷问学生。B访问量提高18%，所以大家学得更好了。应该推广。”

| 维度 | 分数 | 静态理由 |
|---|---:|---|
| 问题界定 | 0 | “好不好”对象/结果不清 |
| 信息评估 | 0 | 将访问次数当学习效果 |
| 方法适配 | 1 | 问卷可能相关，但未说明测什么 |
| 限制与边界 | 0 | 无限制，作出超出材料的结论 |
| 独立决策 | 1 | 有方案，但没有体现比较判断 |
| 理由质量 | 0 | 只复述单一数字并过度推断 |

## 合成作答乙（中等示例）

“我想了解选修课学生能否方便找到指定学习资料。C有42人说比较方便，但不知道总人数；可以再做问卷了解哪些入口难找。结果先只说回答者，不能代表所有课程。”

| 维度 | 分数 | 静态理由 |
|---|---:|---|
| 问题界定 | 2 | 对象、体验及范围相对清楚 |
| 信息评估 | 1 | 发现未知分母，但未讨论自愿填写 |
| 方法适配 | 1 | 问卷与体验有关，测量/抽样理由有限 |
| 限制与边界 | 2 | 限定回答者且指出跨课程外推限制 |
| 独立决策 | 2 | 提出自己的下一步，未机械照搬卡片结论 |
| 理由质量 | 1 | 有具体依据，但理由链条尚不完整 |

## 合成作答丙（较强示例）

“先问‘本课程学生寻找指定资源时主要在哪一步遇到困难’，而不是问平台是否提升学习。B可显示记录到的访问事件增加，但需核对独立用户、课程和重复访问口径；C只代表自愿答题者；A提示可能存在入口问题但不能说明比例。我会先核对日志定义并访谈不同使用经历者，再决定是否设计短问卷。现有卡片不能说明学习效果或全校状况。”

| 维度 | 分数 | 静态理由 |
|---|---:|---|
| 问题界定 | 2 | 范围清楚且可研究 |
| 信息评估 | 2 | 根据三卡各自特点指出证据边界 |
| 方法适配 | 2 | 方法与前置核验/探索目标衔接且有限制 |
| 限制与边界 | 2 | 明确不能推出学习效果和全校状况 |
| 独立决策 | 2 | 给出分阶段方案及本人理由 |
| 理由质量 | 2 | 具体卡片信息支撑决策 |

## 桌面审计结论

- 三种回答可在“是否辨析证据—是否将结论收窄—是否说明方案理由”上产生不同表现。
- 评分演练倾向区分到弱/中/较强，但样例是按量规撰写，存在人为配合评分标准的风险；这不能证明真实作答可区分。
- 三卡没有一张被指定为唯一正确材料；较强示例对三卡作不同用途判断，题面允许其他有依据的顺序和方法。
- A9类判断属于策略而非标准能力测验；任务评分不因是否使用AI而变化。
- 后续若要实施，仍需导师/审批审阅及获批后才可考虑的认知访谈或试测；本文件本身没有完成这些步骤。
