# 研究型学习中的生成式 AI 协作问卷 v0.4（审阅候选）

**状态：审阅候选稿；不得分发；`NOT APPROVED FOR IMPLEMENTATION`。**CORE为15个题组，另有1个OPTIONAL自我感知题组；目标8–12分钟（未实测）。无成熟量表复制，不计算“研究能力总分”或“AI协作能力总分”。

## 开头说明（候选）

本问卷拟了解本科生最近一次研究型学习任务中的经历与做法。这里的任务可包括课程研究/论文、调查报告、大创、挑战杯研究项目、导师课题或其他研究型项目。没有经历或没有使用AI都可以如实选择；无对错评价。请勿填写姓名、学号、具体教师姓名、账号、可识别项目细节或完整AI对话。是否实施、平台、告知与保存方式均须导师及学校程序批准后确定。

**回顾窗口候选：**最近一次符合定义的研究型学习任务；若过去12个月没有，跳至背景/经历题。回顾窗口尚待审阅。

## CORE题组（15组候选）

回答选项中的频率可统一采用“从未 / 偶尔 / 有时 / 经常 / 不记得 / 不适用”，但仅在适合的行为题使用。

| 题组 | 候选题目与回答方式 |
|---|---|
| A1 使用事实 | 最近一次研究型任务是否使用生成式AI？是 / 否 / 不确定 / 无符合任务 |
| A2 使用阶段 | 用于哪些阶段？界定问题 / 判断资料 / 比较方法 / 思考限制 / 写作表达 / 其他 / 未使用（多选） |
| A3 追问条件 | 使用时是否要求AI说明理由、前提或适用条件？是 / 否 / 不记得 / 未使用 / 没有相关输出 |
| A4 来源与依据 | AI给出事实/来源/建议时，你做过哪些处理？检查来源是否存在 / 检查内容是否支持说法 / 与其他来源比较 / 未检查 / 无相关输出 / 未使用（多选） |
| A5 输出处理 | 就最近任务而言，面对AI给出的建议，你最常见的做法是哪项？基本采纳 / 修改后使用 / 只参考部分 / 不采纳 / 未遇到相关建议 / 未使用AI / 不记得 / 其他（单选） |
| A6 意见不一致 | AI建议与原判断不同的时候，你会如何处理？比较依据再决定 / 继续追问 / 保留原判断 / 直接采用 / 未遇到 / 未使用 |
| A7 方法理解与适配协作行为 | 是否要求AI比较不同方法分别能回答什么问题及其限制？是 / 否 / 不记得 / 未使用 / 未涉及方法选择 |
| A8 信息辨识与评估策略自报 | 判断一项研究资料时通常会看什么？来源、发布时间、样本对象、测量定义、是否支持主张、其他材料印证、未检查、不记得（多选） |
| **A9 情境判断** | 情境：“平台资源详情页访问次数上升。”你会采取哪些处理？看指标定义/核对独立用户与重复访问/了解课程覆盖与同期变化/另找能反映学习体验或结果的证据/暂不推断学习效果/其他（多选）。**你最先做哪一步？**选一项并用一句话说明理由。没有单一标准答案；主要观察判断策略。 |
| A10 研究经历类型 | 过去12个月参与过哪些：课程论文/研究作业、课程调查、社会调查、大创、挑战杯或学术科技竞赛、导师课题、科研助理、论文/会议、其他、没有（多选） |
| A11 经历深度 | 对最近/最相关一项，你实际参与过哪些：问题界定、文献/资料、研究设计、数据收集、分析、写作；每项选未参与/协助/主要负责/不适用。仅选最相关经历 |
| A12 训练背景 | 接受过哪些研究方法/资料评价训练：正式课程、工作坊/讲座、自学、无、记不清（多选） |
| A13 最少样本特征 | 专业大类、年级、学校类型（财经类/其他高校财经相关专业/其他/不愿回答）；具体范围和披露风险待审批 |
| A14 指导环境 | 最近任务中是否获得教师/导师/课程/同伴的方法反馈？来源及是否帮助（简短类别）；不要求姓名 |
| A15 风险行为自报 | 是否曾未核验依据便基本照收AI提供的事实、来源或建议？从未/偶尔/有时/经常/不记得/未使用/未遇到 |
| A16（OPTIONAL）自我感知 | 若审阅后认为有必要：对自己判断资料来源和证据支持程度的把握如何？5点自评/不确定/不适用；标记 `SELF_PERCEPTION`，不作能力测验 |

## 跳题、不适用与缺失编码候选

- A1=否时跳过A3–A7、A15中专指AI交互的部分；A8、A9、经历、训练、样本特征和指导环境仍作答。
- 没有符合任务者不回答该任务的行为回顾题，进入A10以后背景题；不得把“无经历”编码为行为缺失或低能力。
- “未使用AI”“没有相关输出”“未遇到”和“未回忆/不确定”须分开编码；不得都编码成0。
- 数据字典候选码：结构性跳题 `NA_SKIP`；明确不适用 `NA_APPL`；不愿回答 `NA_REFUSE`；不知道/记不清 `NA_DK`；系统漏答 `NA_MISS`。实际数据格式和平台实现待审。
- A5固定为“最常见做法”单选；若后续需要记录所有处理行为，应另作工具修订并重新审阅，不在本版混合单选与多选。

## 负担与边界

CORE 15题组，另1个OPTIONAL题组；部分题为多选或简短说明，8–12分钟为未验证估计。A16可因负担移除。没有长量表、知识测验或心理构念扩展。A16只反映自我感知，A8是自报策略，A9是情境策略，三者都不能替代短任务。问卷与短任务是否关联见 [`22_问卷与短任务关联方案.md`](../22_问卷与短任务关联方案.md)，默认不建立真实个体标识。
