## 解释边界

问卷为主要证据，但题组混合事实、分类行为、自报策略、单题情境和可选自我感知；不计算总分，不对全表做 Cronbach α/KMO/因子分析。短任务作为不同来源的可观察表现分项呈现。若后续拟做问卷—任务关联，须先获批个人级链接并在预分析计划中确定方法；否则只作样本层面的并列描述。无论统计关联方向为何，都不解释为生成式AI造成能力变化。
