# 评分员培训与校准包（候选）

**状态：**`DRAFT_NOT_FOR_USE`、`SYNTHETIC_ONLY`；当前没有评分员、真人作答或校准活动。本文最初按 v0.4 六维结构编写；v0.5 candidate 提出后，训练包需在审阅后另行对齐。本文示例完全虚构，不作为参与者答案或研究结果。

## 评分前规则

1. 只评分研究设计短任务 A 指定的书面可见内容；不根据学生身份、学校、专业、AI使用或经历推测能力。
2. 不使用姓名、学号或评价学生个人；未来获批时评分材料须去标识并与身份映射分开保存。
3. 每个维度独立判断，先记录证据片段和规则，再给0/1/2；不把分项相加为能力总分。
4. 允许多种合理研究问题、材料排序和方法方案；按论证是否适合问题评分，不按答案是否等于示例评分。
5. 采纳AI建议本身不加分或扣分；只有作答是否解释个人取舍可作为决策证据。
6. 未答、题目未展示、不适用、任务中止、维度不可评分分别编码；不得默认填0。

## 维度判定边界

| 维度 | 可计入的可见证据 | 不计入/不得推断 |
|---|---|---|
| 问题界定 | 对象、现象、范围及可回答性 | 专业术语数量、研究题目“宏大程度” |
| 信息辨识与评估 | 对资料来源/样本/指标/支持范围的准确判断及影响 | 仅提“有偏差”但无卡片依据；文笔流畅 |
| 方法适配 | 方法为何能回答问题、数据要求及方法限制 | 方法名复杂；是否选择研究者偏好的方法 |
| 限制与边界 | 明确限制如何收窄结论、仍需何证据 | 重复给同一条材料属性加分 |
| 独立决策 | 最终选择由本人承担，并能说明取舍 | 是否听从AI、是否坚持先验意见 |
| 理由质量 | 理由可回到题目/材料/方法的整体链条 | 字数、表达风格；已在前维计过的同一事实 |

## 合成校准例（不可当作真人数据）

### 合理方案甲：先核平台口径再做课程访谈

虚构作答：“我先确认详情页访问是次数还是独立用户，再访谈不同使用经历的本课程学生；留言只说明有人遇到入口问题，42份自愿反馈只能说明回答者，不能代表全校。”

评分讨论：信息辨识和边界表现较清楚；方法适配需看研究问题是否明确；不能只因答案提到了预设核查步骤就机械打满分。

### 合理方案乙：先补齐反馈表分母，再安排短问卷

虚构作答：“我想了解选修课学生遇到的查找困难，先问清42份反馈的发放人数和题目，再决定是否用短问卷描述本课程情况；这仍不能证明资源影响学习效果。”

评分讨论：虽没有先选访谈或先核B卡全部指标，仍是合理选择；按问题与方法衔接计分。

### 边界答案丙：理由略短但关键边界明确

虚构作答：“B只数访问，不能说明成绩变化。我先查是否重复访问。”

评分讨论：可在B卡的信息判断/边界上识别具体证据；不得仅因简短而判低，其他维度若无证据应记未呈现而非推断欠缺。

### 明显推断错误丁

虚构作答：“访问增加18%，所以资源让全校成绩提高。”

评分讨论：对现有卡片支持范围超推断；只在相关维度记录该作答证据，不跨维度重复扣分。

## 分歧处理候选流程

1. R1、R2独立评分，不查看对方得分或身份背景。
2. 锁定首轮评分，再汇总逐维差异；不得先讨论后填分。
3. 依据作答原句和评分锚点讨论；不能达成一致时保留两份原始评分并交第三位裁定者，裁定理由单独记录。
4. “无法判断”或题目不提供可观察机会时使用 `NOT_SCORABLE`；不可把不可评分强行转为0。
5. 正式双评比例、盲评字段、仲裁规则与评分员培训量待审批和资源确认。

## 校准门槛候选

若未来获批并实施：先以预先编写的虚构边界作答培训，不用真实学生回答作为未同意的训练材料；确认评分分歧类型、修改规则并留版本。之后另行决定双评比例、加权 Cohen's kappa 是否可估、何种维度/样本下报告。校准包本身不证明可靠性。
