# AI协作行为编码手册 v0.1

**DRAFT — NOT VALIDATED。**本手册只做行为描述，不生成或汇总未经验证的“AI协作总分”。编码对象是任务相关回顾记录及经批准可用的任务产物；缺失记 `NA`，不要把未观察到误作能力缺陷。类别定义不要求每个行为都出现。

| 编码 | 操作定义与取值 | 正例 | 反例 | 边界情况 |
|---|---|---|---|---|
| 使用阶段 | 多标签：问题/材料/方法/限制/最终判断/未使用 | 在方法选择时求备选 | 只写“问了AI”而不知阶段 | 阶段不清记 `UNCLEAR` |
| 交互轮次 | 单轮 / 多轮 / 未知 | 初答后再追问适用条件=多轮 | 多次独立新话题不一定是追问 | 只记得“问过几次”可记轮次但阶段未知 |
| 追问理由 | 是/否/未知；明确要求说明依据或理由 | “为什么这个方法适合？” | “再写详细点” | 请求举例但未要理由，不编码为是 |
| 追问信息来源 | 是/否/未知；要求出处、可核查来源或来源类型 | 要求说明材料依据 | 仅要求“更准确” | 要求参考文献但未核实，仍只记“要求来源” |
| 要求反例 | 是/否/未知；明确要求反例或失败条件 | “什么情况下这个建议不适用？” | 让AI列优点 | 询问风险但非反例，备注后不自动计是 |
| 比较备选 | 是/否/未知；要求或实际比较两个以上选项 | 比较问卷和访谈适用性 | 只接受首个方案 | AI给出备选但学生未比较，记输出出现，不记学生主动比较 |
| 发现AI问题 | 未报告 / 指出问题 / 不确定 | 指出建议把相关说成因果 | 只说“我不喜欢” | 若材料无法判断真伪，标记待核而非确证错误 |
| 修改AI输出 | 是/否/未知；有可辨认的实质修改 | 改窄研究对象并解释 | 仅改标点格式 | 润色但含义变化不清时记不确定 |
| 拒绝AI建议 | 是/否/未知；明确未采用至少一条建议 | 因超出资料范围而不采用 | 采用建议后另加细节 | 未记录建议内容时不推断拒绝 |
| 独立解释方法 | 无 / 部分 / 清楚 / 未知；能用自己的话解释适配与条件 | 说明访谈能了解经历但不能估总体比例 | 复述AI术语但说不出含义 | 短答不能自动判为无理解，记未知/部分并留证据 |
| 最终决策权 | 学生作出 / AI建议被直接照搬且无独立说明 / 共同形成但学生确认 / 未知 | 学生选择并说明取舍 | 记录明确表示照搬不审阅 | 产物相似不等于照搬；无过程信息记未知 |

推荐每条编码保留简短证据片段或记录行号；不给行为贴“好学生/差学生”标签。回顾材料受记忆偏差影响，单个类别不等于稳定特质。编码训练、双编码和一致性评估须在审批后另行制定；目前不定阈值或合成分数。
