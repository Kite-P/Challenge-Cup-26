# AI协作任务后轻量回顾记录 v0.1

**草案——未经批准，不得使用。**只适用于获批后的任务；不收集整个账户历史。建议任务结束后约2–4分钟回顾关键交互，且不要求逐字还原。回忆会有遗漏、顺序偏差和概括误差，应与答卷分开解释，不能当作完整操作日志。

| 字段 | 填写方式 |
|---|---|
| step_id | 对应任务步骤1–5；一次记录一个关键交互 |
| research_stage | 问题界定 / 材料判断 / 方法选择 / 限制分析 / 最终判断 / 其他 |
| student_goal | 当时想解决什么（短语即可） |
| prompt_summary | 提示词概要，不要求复制全文；请去除身份和隐私信息 |
| follow_up_used | 是 / 否 / 不确定 |
| asked_for_reason | 是 / 否 / 不确定 |
| asked_for_source | 是 / 否 / 不确定 |
| asked_for_alternative | 是 / 否 / 不确定 |
| AI_suggestion_summary | AI关键建议概述（若无则不适用） |
| student_action | accepted / modified / rejected / no AI / unsure，可多选并简述 |
| reason_for_action | 采纳、修改或拒绝的理由；不要求评价个人能力 |
| student_final_decision | 参与者最终决定（短句） |

最多记录三段最关键交互；若交互很多，选择最影响最终判断的内容，不提交未筛选聊天记录。此表是待审设计，不证明AI使用合规性，也不作为单独表现得分。
