# 问卷 v0.6 分析映射（候选）

| 研究内容 | 题目/变量 | 首选描述 | 可选分析及边界 |
|---|---|---|---|
| 使用情况与环节 | Q7–Q8 | 比例、环节多选共现 | 专业/年级分组须先检查样本构成及小格，不推断总体代表性 |
| 信息核查 | Q9–Q13 | Q10状态、对象、方式分别汇报；Q13多选频数 | 组间关联仅作描述/适当检验；核查自报不等于核查正确 |
| 方法理解与决策 | Q14本人行为与AI比较拆分 | 是否涉及方法、本人行为及AI比较分别描述 | 不把“要求AI比较”当作理解或选择能力 |
| 未核验采纳 | Q15 | 类别分布及缺失 | 不由自报频率推断实际错误率 |
| 培养需求 | Q16 | 多选需求比例及群体画像 | 多选不求和为100%；“无额外需求”等互斥 |
| 短任务 | 任务五维表现 | 分项分布、评分者一致性 | 只解释固定任务的可观察表现；不得合成稳定能力或与问卷自评混为同一尺度 |
| 访谈 | 学生/教师 | 主题、反例、语境 | 解释机制，不估计比例；保留反例及编码过程 |
| 企业需求 | 合法招聘文本画像 | 来源、时间、岗位覆盖及编码频率 | 仅代表采集框与时间，不等于劳动市场总体或学生能力缺口 |

默认先做样本流、缺失、描述统计和交叉表；推断检验按变量量尺、稀疏程度和抽样设计选取。回归须有充分样本、先验研究问题和可辩护控制变量；不默认SEM、潜类、中介调节或复杂优化。横截面关联不作AI使用导致能力变化的因果解释。正式分析计划及N均 `PENDING`。
