# 教师半结构访谈提纲 v0.1

**DRAFT — NOT APPROVED OR CONDUCTED。**目标20–30分钟，未实测。获批后方可招募教师。不开启对学生个体的评价，不索要可识别学生案例或内部材料；访谈只用于理解教学观察与支持需求。

| 主题/主问题 | 中性追问 |
|---|---|
| 学生使用AI的变化 | 您观察到哪些变化？不同课程/任务是否不同？ |
| 学生常见困难 | 在研究问题、信息判断或方法选择中，常见困难是什么？能否给去标识化例子？ |
| 如何判断学生是否理解任务 | 哪些可观察表现能帮助区分理解与仅提交流畅文本？哪些表现也可能被误读？ |
| 教师如何看AI协作 | 哪些用途可能有帮助，哪些情境需要额外审慎？有无不同看法？ |
| 学生对研究方法的理解 | 学生通常如何说明方法为什么适合？您希望他们考虑哪些条件？ |
| 信息评价 | 学生使用资料时通常如何判断相关性、来源和依据？ |
| 独立判断 | 学生如何处理与AI建议不一致的情况？有哪些不确定或难以观察之处？ |
| 课程/科研训练规则 | 当前规则中哪些清楚、哪些仍需解释？ |
| 学校支持需求 | 对帮助学生形成可解释的研究判断，您认为何种支持值得考虑？ |

全程避免“AI是否让学生变懒”等诱导表述。录音需单独同意；教师身份、职务和具体课程信息是否收集均为 `PENDING`。当前未联系或访谈教师。
