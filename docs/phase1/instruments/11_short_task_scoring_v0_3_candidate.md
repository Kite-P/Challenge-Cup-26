# 短任务分项评分框架 v0.3（候选）

**状态：**候选框架，未验证、未校准评分者，未用于任何参与者产物。不得把分项相加称为总体科研能力。

| 分项 | 观察证据 | 评分要点（待定 rubric） |
|---|---|---|
| 问题界定 | 问题表述及范围 | 可研究性、对象/现象清楚、不过度宽泛 |
| 信息辨识与评估 | 对三张卡的判断及理由 | 相关性、来源可信/可查、主张依据、证据与结论匹配、交叉核验、识别 AI 错误/幻觉与过度推断、优先核验选择 |
| 方法理解 | 方法选择及解释 | 方法与问题匹配、适用条件、数据能支持及不能支持的结论 |
| 独立研究决策 | 对建议的处理及最终说明 | 比较备选项、采纳/修改/拒绝理由、限制与边界、最终决策责任 |

可先用分项描述等级或锚点；未训练和未开展一致性评估前不报告评分可靠性。是否双评、评分者培训、盲评方式和等级定义须在审批及正式实施计划中另行确定。
