# 挑战杯结果表图规划（候选）

以下仅为将来在研究获批、数据取得且质量审查后可考虑的呈现接口；不代表当前有研究结果。最终表图数量应服从研究问题与数据质量，不为“完整”而增加模型。

| 编号 | 候选呈现 | 核心分母/边界 |
|---|---|---|
| 表1 | 学生样本背景和研究经历 | 报告实际招募与缺失，不外推总体 |
| 表2 | AI使用事实、阶段与协作行为 | 以符合回顾条件者为分母；非使用者不进入过程题分母 |
| 表3 | 信息辨识与评估策略、方法理解与适配及独立研究决策的自报/情境策略 | 分项描述，不合成成熟量表或客观能力分 |
| 表4 | 短任务候选五个维度表现分布 | 仅任务参与者；不使用科研能力总分；最终维度待冻结 |
| 表5 | 评分者分歧与一致性摘要 | 说明双评比例、分歧规则和缺失 |
| 表6 | 学生—岗位能力维度结构映射 | 仅真实岗位数据合法可用时；保留 `DIRECT/PARTIAL/NO_DIRECT_MATCH` |
| 图1 | 学生经历和样本结构 | 明示样本来源 |
| 图2 | AI协作阶段及输出处理 | 仅实际AI使用者相应过程分母 |
| 图3 | 短任务候选五维分项分布 | 不连成能力总分 |
| 图4 | 岗位族与多标签能力画像 | 需真实数据许可；不得解释为全部企业需求 |
| 图5 | 学生证据与岗位需求结构对照 | 仅做定性/分项结构映射，不计算Gap Score |
