# 分析方案 v0.1

**状态：**预注册式思路草案，不是正式预注册，不存在本项目采集数据或结果。

## 证据结构

分别管理四类材料：问卷自报、任务产物评分、访谈主题、课程/学校背景。只有在同一参与者可合法关联且批准方案明示时才做跨来源匹配；默认不收直接身份标识。形成数据前不得预设具体模型或变量编码。

## 基础分析

1. **描述统计：**报告样本来源、专业/年级构成、研究经历、AI使用阶段/频率、缺失和参与负担；便利样本不作总体比例推断。
2. **测量质量：**成熟量表按原计分与许可条件处理；翻译/改编先做内容审查与认知访谈。结构分析取决于样本和工具，不为追求“量表验证”机械跑EFA/CFA。
3. **任务评分：**训练评分者、盲评条件允许时做双评分；报告分项分布及与等级类型相匹配的一致性统计。没有实际双评就不声称评分可靠。
4. **自评与表现：**先分别描述，再报告关联和不一致情况；不把差异直接命名为“高估/低估”，不以单次任务代表稳定能力。
5. **关联分析：**研究协作维度与任务表现分项的关系，先呈现原始分布/效应估计与不确定区间，并控制少量事先有理论理由且可测的因素。横截面关联不写成因果影响。
6. **质性材料：**访谈主题围绕阶段、选择、核查/修正、理解与指导；建立编码本、保留反例，说明研究者立场和分歧处理。

## 组间比较

只有在组别有理论含义、定义可复核且样本量支持时，才比较专业大类、研究经历或AI使用情境。需检查量尺等值性/任务差异和多重比较；不将便利样本差异解释为群体本质差异。

## 条件性方法（CONDITIONAL）

- 回归：主要变量定义明确、数据结构和样本支持、混杂因素预先论证时。
- 中介/调节：有明确理论路径、时间顺序或适当设计与足够统计功效时；横截面中介不作为机制因果证明。
- 潜在分类/剖面：样本规模、指标质量和类别稳定性支持且研究问题确有需要时。
- 多层模型：存在足够学校/课程簇且簇数支持时。

## 不默认使用

SEM、DID、IV、PSM、机器学习预测等不因“复杂”而采用；没有相应识别设计、样本结构或预测目标时不使用。企业DTA和Stata不属于本阶段分析；本轮未运行Stata。

## 缺失、稳健性与解释

先区分结构性不适用与漏答；报告缺失模式。数据生成后再按缺失机制、任务评分误差及替代操作化制定稳健性分析。报告估计不确定性、效应方向与可能零结果，保留不支持原先直觉的结果。

## v0.2 数据连接与分析层级

### 跨来源连接规则

- 默认问卷、任务、学生访谈、教师访谈分别保存，不做个人级链接。
- 只有审批允许、参与者对该连接单独知情且研究问题确需时，才以随机 `participant_id` 连接同一人的问卷与任务/访谈记录。
- 联系信息（若经批准确需用于安排访谈）单独保存，访问权限与研究数据分离；不在分析文件中保留姓名、学号、账号或可识别聊天历史。
- 教师访谈不与学生个人记录链接；只作独立主题资料。
- 未获批的连接设计保持 `PENDING`，不得先行创建参与者台账或收集数据。

### 分析层级（条件性路线，不代表当前已选定模型）

1. **Level 1 — 描述：**样本构成、AI协作方式、信息评价/方法理解/独立研究判断相关指标与任务分项表现。
2. **Level 2 — 测量质量：**检查题目可理解性、缺失、评分者一致性；是否做结构检验取决于工具定位与实际样本，不以量表开发为目标。
3. **Level 3 — 自报与表现：**在获准链接且样本支持时描述自报与任务表现的对应及偏离，不把差异直接解释为高估/低估。
4. **Level 4 — 协作行为与任务表现：**探索记录到的AI协作方式和任务分项之间的关联，不作因果断言。
5. **Level 5 — 条件关联模型：**仅在理论、样本、测量、设计及审批均支持后另行确定模型与协变量；目前为 `OPTIONAL / PENDING`。

不预设显著性、正向效果、中介或调节；不增加心理构念或量表以扩展模型。分析方法和正式N仍待导师确认及后续数据条件评估。
