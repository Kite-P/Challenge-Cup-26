# 问卷与短任务预测试方案（待审批候选）

**状态：**`PENDING`；当前不得招募、联系、试填、访谈、发放问卷或采集任何真人数据。项目保持 `PILOT_BLOCKED`。

## 目的

本文件只规划未来在导师和适用机构书面确认后，如何判断问卷与约10分钟短任务是否容易理解、流程是否可行、材料是否产生非预期歧义。它不表示已批准或即将开展预测试，不预设人数、日期、学校、补偿、平台或招募渠道。

## 进入条件（全部满足后仍需重新授权）

1. `CURRENT_CYCLE_RULES_PENDING` 已由正式通知核实到适用于团队的赛道、资格与提交规则；
2. 适用学校/机构以书面方式确认审批/备案要求及责任部门；`OFFICIAL_PROCESS_NOT_FOUND` 不得解释为免审；
3. 导师确认拟审版本、研究范围、是否允许AI和预测试目的；
4. 招募渠道及所在机构要求获得许可；跨校时取得相关书面许可；
5. 参与者说明、知情同意、退出方式、数据最小化、记录/录音、存储/访问/期限/销毁规则完成审阅；
6. 方案明确预测试不是正式样本，不将小规模反馈用于效果推断；由用户/导师再作是否启动的人工决定。

任何条件未满足，状态维持 `PILOT_BLOCKED`，不进行下一步。

## 获批后才可讨论的检查内容

| 工具 | 未来核查项 | 可能的桌面修订证据 |
|---|---|---|
| 问卷 v0.5 | 研究型学习任务定义是否一致理解；过去12个月回忆口径；无任务/未用AI/不确定/拒答路径；题组负担与敏感信息边界 | 对题意的复述、路径走查、用时区间和不适用项反馈；不把意见解释为量表效度 |

| 五维评分 v0.5 | 0/1/2 与 `NOT_SCORABLE` 区分；信息属性和结论边界是否重复计分；是否受文笔或AI方向影响 | 评分员训练/独立判定/分歧案例记录；所有数量和一致性指标必须在审批与方案确认后决定 |

## 风险控制与停止规则（拟议，待机构审查）

- 不收集姓名、学号、账号、完整AI提示词或聊天记录；不把问卷、任务和访谈数据关联，除非另有批准及清楚同意。
- 参与者可拒答或停止；未来具体退出及数据处理规则须由获批文件确定，当前不作承诺。
- 遇到不适、隐私泄露、未成年人、审批边界不明、工具超出获批版本或参与者误以为影响成绩/师生关系时，暂停活动并按正式批准程序处理。
- 记录仅可在获批范围内做最小必要存储；不在公开仓库保存真人数据或可识别原始材料。

## 预测试后版本决策

若将来获批开展，逐条记录“观察到的问题—来源—修改/不修改决定—影响题项/变量/评分—新版本”。只有导师和机构要求确认后，才可决定冻结工具或是否申请下一阶段。一次可行性检查不证明代表性、信效度、因果效果或竞赛合规性。
