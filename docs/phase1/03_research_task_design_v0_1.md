# 短科研任务设计 v0.1

> 历史长版草案：时长与材料结构已由 Phase 1C 候选短版更新；不代表当前任务版本。当前见 `instruments/01_research_task_A_v0_3_short.md`。

**草案——未经批准，不得实施。**

以下为候选工具，不面向学生发放或实施；材料需后续认知访谈、试测、导师审阅和审批。

## 共通设计原则

- 任务模拟低门槛研究训练，不考专业记忆；所有材料、术语和必要背景在题面提供。
- 学生需提交简短产物和理由，以观察决策过程；不以“是否用了AI”代替表现。
- 未来若获批允许使用AI，统一说明可用工具/时长/联网规则，并要求保存提示与输出；另设无AI方案仅作方法设计候选，不能事后混合比较而不记录条件。
- 初版优先采用透明错误识别：任务材料明确说明其中含有“待评价的AI建议”，不伪装成真实可靠建议，不欺骗参与者。
- 尚无真实材料、正式评分或学生结果。

## 候选任务 A：研究问题与设计判断（推荐主任务）

| 项目 | 设计草案 |
|---|---|
| 目标 | 从一个宽泛财经/校园议题中提出可研究问题，并匹配可行资料与方法；观察方法理解和独立决策 |
| 材料 | 约1页中性议题简介、简短变量/资料卡、两条相互竞争的研究问题示例；不使用真实个人/企业数据 |
| 学生操作 | 写出研究问题；说明需要的观察单位、核心概念、可用资料与一种合适方法；指出一个限制并解释为何舍弃一个替代设计 |
| AI权限候选 | 可设统一的允许AI条件，要求保留交互记录；另将“无AI”作为后续实验条件候选，须单独审批，不在本轮执行 |
| 预计时间 | 25–30分钟（设计估计，需认知访谈验证） |
| 观察构念 | 问题界定、信息相关性判断、方法适配、理由质量、决策权/理解 |
| 候选评分 | 用04号量规按行为锚点评问题、方法、限制与解释 |
| 难度 | 低至中；不需高级统计 |
| 风险 | 题面可能暗示唯一正确方法；财经专业背景仍可能造成熟悉度差异 |
| 伦理/公平 | 使用虚构或公开且去标识化材料；避免涉及敏感个人财务经历；提供等量背景信息 |
| 外部帮助风险 | 居家作答时可能请他人代答；若未来实施，需统一时段/记录AI日志，但不得做侵入式监控 |

## 候选任务 B：多来源信息评价

| 项目 | 设计草案 |
|---|---|
| 目标 | 判断哪些信息与一个研究问题相关、来源和依据是否充分，并说明如何补查 |
| 材料 | 3–4条短摘要/网页截取，来源类型和发布日期明确；至少一条证据薄弱但不以明显错误诱骗 |
| 学生操作 | 选择可用材料；评价相关性、来源、依据和局限；指出下一步核查路径 |
| AI权限候选 | 若允许AI，给出统一的AI摘要并要求评价；不得隐瞒其生成来源 |
| 预计时间 | 20–25分钟 |
| 观察构念 | 来源评估、信息相关性、主张—依据区分、交叉查证策略、判断解释 |
| 候选评分 | 评价要素覆盖、依据引用、局限说明和可执行查证建议 |
| 难度 | 低至中；依赖阅读理解 |
| 风险 | 阅读速度/语言能力影响得分；来源熟悉度偏差 |
| 伦理/公平 | 用同一语言难度和长度；提供基本背景词汇；不要求真实账号或开放网络登录 |
| 外部帮助风险 | 搜索或他人协助会污染过程数据；未来明确工具条件、记录操作，不作惩罚性监控 |

## 候选任务 C：方法/结果解释与错误诊断

| 项目 | 设计草案 |
|---|---|
| 目标 | 解释简单表格/图与一段研究建议，判断结论是否超出材料支持范围 |
| 材料 | 小型虚构汇总表、研究问题、简化方法说明，以及明确标注为“AI生成、需审阅”的分析建议 |
| 学生操作 | 用自己的话解释结果；指出AI建议中可能的问题；提出修订结论和仍需的信息 |
| AI权限候选 | 题面直接给出AI建议作为待评对象；如学生也可调用AI，必须记录两种AI来源并防止混淆 |
| 预计时间 | 25–30分钟 |
| 观察构念 | 数据解释、方法理解、错误识别、因果/相关区分、结论谨慎性 |
| 候选评分 | 错误定位、理由、修正及不确定性表达 |
| 难度 | 中；需防止数学基础差异 |
| 风险 | 过度依赖单一错误模板导致测到“猜题”；人工编制错误可能不具生态效度 |
| 伦理/公平 | 材料明确告知建议可能有误；不存在隐藏欺骗。若未来采用隐瞒错误/来源的 deception，须单独 `ETHICS_REVIEW_REQUIRED`，本方案不采用 |
| 外部帮助风险 | AI/搜索可直接生成解释；若允许AI，重点评分过程证据和修订理由；若不允许需说明并统一监考条件 |

## 建议组合与取舍

建议先以 **候选任务 A** 为主任务草案：对财经专业知识依赖较低、能贯通研究问题—方法—局限，最贴近项目核心。B可作为信息评价模块，C作为备选而非强行叠加。若三项全做，预计总任务时间将超过合理短测时长，并引入疲劳与多构念混杂。建议后续先让导师审阅 A 及透明呈现错误材料的方案，再决定是否保留 B/C。

本轮没有试测、评分或正式实施；所有时长均为设计估计，不代表完成时间实测。
