# 企业二手数据与大挑调研合规风险

企业岗位文本拟作为**补充需求侧证据**，不作为项目主体或学生调研替代品。其是否符合本届社会调查作品要求尚不能判断，标记 `COMPETITION_RULE_INTERPRETATION_RISK`。

| 方案 | 定位 | 当前处理 |
|---|---|---|
| A：二手背景 | 只用于背景说明，报告主体由学生团队一手调查形成 | 可作为以后评估选项；需核对来源许可与本届规则 |
| B：团队参与编码 | 项目组定义范围、分类、编码手册，对人工样本编码并报告一致性 | 可能提高团队可审计参与，但不自动满足竞赛规则；不在本轮获取数据 |
| C：未来企业访谈 | 经审批后作为可选补充 | 当前不联系企业、不安排访谈、不强行纳入 |

不能宣称岗位词频代表企业总体需求、企业绩效或学生能力缺口。取得数据前需核验许可、使用范围、抓取/访问条款、可引用方式及个人信息处理。当前无招聘数据、无联系、无分析。最终以当前周期官方规则及人工合规确认决定。
