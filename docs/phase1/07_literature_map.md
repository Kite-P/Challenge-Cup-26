## 主题—证据地图

| 主题 | 可用认识 | 对本项目的设计启示 |
|---|---|---|
| 高等教育GenAI | 研究关注从工具使用转向任务、学习和评估情境；不同学科与任务差异明显 | 不用笼统“使用AI”解释一切；明确任务阶段、规则和产物 |
| AI literacy / GenAI literacy | 已有自评量表和客观测验；概念覆盖知识、使用、评价、伦理等，不同工具目标不一 | 作为候选背景构念；不把AI素养等同研究能力 |
| 批判性思维/认识论判断 | 信息判断涉及依据、来源、多个来源印证、结论确定性；“判断质量”须落到理由和行为 | 评分理由和查证路径，不只看选项对错 |
| 信息素养/在线信息评价 | EVON模拟搜索环境测相关性和可信度；真实网络判断研究常观察来源、目的、证据和交叉印证 | 设计多来源短材料任务；控制阅读负担并报告情境边界 |
| AI辅助写作/研究 | AI可能参与构思、解释、改写等不同阶段；单问是否使用会遮蔽流程与决策权 | 问卷/任务记录阶段、交互深度、输出处理和最终决定 |
| 人机协作 | 重要差异可能包括谁提出候选、谁评价、谁作最终决定，以及用户是否理解输出 | 以协作维度作为描述框架；不预先构造未经验证的总分 |
| automation bias / overreliance | 自动化建议可能被不恰当地采纳；“信任/依赖”与实际采纳行为并非同一概念 | 分开测态度自评和任务中的采纳/修改行为；不把错误归因于AI单方 |
| metacognition / self-report | 自我感知能力与客观表现并非同一指标，相关不完美 | 把自评与行为任务并列，检验一致与偏离而不互相替代 |
| research skills | 研究型任务包含问题界定、信息评价、方法适配、结果解释与限制说明 | 主任务聚焦问题—方法判断，另以子维度记录表现 |

## 自评与表现测量的区分

自评回答的是学生“认为自己如何使用/理解/判断”；表现任务观察的是其在特定题目、时间和工具条件下“实际完成了什么”。二者受到不同误差影响，不应直接相减生成能力差值或宣称自评失真。分析时报告各自测量质量、相关与不一致案例，并避免把单次任务表现概括为稳定的整体科研能力。
