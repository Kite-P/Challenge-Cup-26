# 研究问题 v2（候选）

**状态：**设计草案，未冻结；`PILOT_BLOCKED`。对象暂指财经相关专业本科生，学校、年级、样本框和样本量均待确认。

## 总问题

在研究设计型学习任务中，财经相关专业学生如何与生成式 AI 协作；其协作方式如何与信息辨识与评估、方法理解、独立研究决策及可观察任务表现相关？另以企业招聘需求作为补充背景，谨慎比较需求文本与学生侧表现中能力主题的对应情况。

## 子问题（最多四项）

1. 学生在研究问题界定、材料评价、方法选择与限制分析等阶段如何使用、审查、修改或拒绝 AI 输出？
2. 学生自报的信息辨识与评估、方法理解及独立研究决策，与短任务中可观察的分项表现呈现何种对应或不一致？
3. 不同 AI 协作方式与任务分项表现之间呈现何种描述性关联；在何种研究经历背景下可能出现差异？不作因果预设。
4. 若招聘文本取得授权并可分析，企业岗位需求中哪些能力主题可与学生侧任务表现直接、部分或不能直接对应？

## 边界

问卷为学生端主要证据；短任务和访谈为补充。企业端不进入学生主线模型，不开展企业绩效分析、政策评估、因果识别或所谓“供需差距分数”。具体工具、测量和分析均为候选。
