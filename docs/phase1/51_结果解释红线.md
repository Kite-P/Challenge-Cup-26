# 结果解释红线与写作词典

当前无真人/企业数据，不产生研究结果。未来撰写时按下列界限检查：

| 证据 | 不能等同于 | 推荐表达 | 避免/需强证据表达 |
|---|---|---|---|
| 横截面问卷关联 | 因果影响 | “与……呈现关联” | 导致、提升、降低、造成 |
| 自报行为/信心 | 实际能力或行为观察 | “参与者自报……” | “学生具备/缺乏能力” |
| 单次特定任务 | 全面科研能力/稳定特质 | “在本任务中表现为……” | “总体科研能力高/低” |
| 岗位文本编码 | 企业整体战略/真实能力重要性 | “在所分析且获许可文本中出现……” | “企业普遍最重视……” |
| 岗位词频/占比 | 市场总体需求/学生能力缺口 | 报告来源、范围、分母、编码定义 | Gap Score、供需差距已被证明 |
| 不使用 AI | 低AI能力 | “本次任务未使用 AI” | 依赖/能力不足 |
| 使用 AI | 高能力或高收益 | “记录到使用/某种协作行为” | AI赋能、提升表现 |
| 合成数据 | 真人行为结论 | “模拟流程检查显示……” | “研究发现……” |

允许优先使用：相关、关联、呈现、自报、在本任务中观察到、所分析文本中出现。谨慎使用：影响、提升、降低、造成、导致；即便研究问题使用因果术语，也须由识别设计支持，不能由措辞替代。
