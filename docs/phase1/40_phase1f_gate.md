# Phase 1F Gate

## 代码与模拟流程 Gate

Phase 1F修正严格跳题与任务状态/评分分析逻辑，按固定种子重生成模拟数据，运行校验、问卷/任务/关联/评分者/企业模拟分析及映射，31项单元测试与完整模拟流水线通过。具体计数见 `results/synthetic/data_quality_report.md`；模拟通过不表示真实研究通过。

独立复核中的两项 IMPORTANT 均为 `RESOLVED`：严格问卷跳题树；不完整任务评分与完整六维均值排除。

## 竞赛方向 Gate

- 比赛类型：`CONFIRMED_BIG_CHALLENGE`。
- 备赛方向：`CONFIRMED_MAIN_TRACK_DIRECTION`。
- 状态汇总：`COMPETITION_DIRECTION_CONFIRMED`；本届规则 `CURRENT_CYCLE_RULES_PENDING`。
- 往届校内经·观：`HISTORICAL_REFERENCE_JINGUAN`，不得冒充本届名称。
- 本届赛道与规则：`WAIT_OFFICIAL_NOTICE`；当前入场路径 `CURRENT_CYCLE_ENTRY_PATH_UNCONFIRMED`。
- 项目成果框架：候选哲学社会科学类社会调查报告；学生一手证据为主体，企业二手招聘材料仅补充且存在规则解释风险。

## 真人研究 Gate

状态保持 **`PILOT_BLOCKED`**。没有招募、试测、发问卷、访谈、任务实施或真实数据采集。学校审批路线、样本渠道、工具最终版本、竞赛本届规则、招聘数据及许可仍待确认。`COMPETITION_COMPLIANCE` 与 `RESEARCH_APPROVAL` 是独立门禁。不得写成 `PILOT_READY`。

## 退出条件

没有完成全部技术验证、发现未清零、或任何真人研究前置条件未满足时，不得宣称研究准备就绪。正式 v0.3 仍为 candidate，未冻结。
