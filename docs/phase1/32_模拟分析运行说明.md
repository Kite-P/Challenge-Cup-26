# Phase 1F 模拟分析运行说明

**本文件为模拟流程说明，不得用于研究结论。**模拟数据规模不是正式样本量建议。

## 运行与依赖

使用项目已有 Python 3.14.7，不安装包，不改全局环境。统一入口为 `python -m src.run_phase1e_synthetic_pipeline`，依次生成并校验模拟数据，再运行问卷、任务、关联、评分者一致性、企业画像、结构映射和图表。当前运行结果、软件版本和数据计数以 `results/synthetic/data_quality_report.md`、`execution_environment.json` 为准；Phase 1E 的旧测试结果仅为历史记录。

Phase 1F 脚本将 COMPLETE 标记兼容 pandas 的布尔推断，并在CSV读取后显式恢复分数数值类型；`PARTIAL`/`ABORTED`不进入完整六维均值，未评分维度不进入双评分者一致性。模拟数据本身固定版本为 `phase1f_validation_v1`。

## 输出

- 问卷脚本输出分项频数/比例，包括经历、AI事实/阶段、追问、依据、输出处理、冲突、方法比较、信息行为、A9、指导背景和未核验采纳。
- 任务脚本输出完成情况、AI使用分层和六维分项描述；不形成综合能力分。
- 关联脚本输出问卷—任务链接、AI实际使用者过程字段及任务参与/未参与者在年级、经历、AI使用和学校类型上的描述分布。
- 评分脚本输出精确一致率、平均绝对差和分维度分歧数。本环境未安装 statsmodels，当前流程也没有合适的预装加权Kappa实现，因此不计算加权Kappa；不为此安装依赖。
- 企业脚本输出岗位族、八个模拟标签维度及岗位族/年份交叉摘要。标签源标为 `SIMULATED_GROUND_TRUTH`，只用于验证程序。
- 映射表使用 `DIRECT/PARTIAL/NO_DIRECT_MATCH`，不计算 `Gap Score`。

## 禁止解释

所有频数、比例、均值和图形均由人为指定的随机生成机制产生，不是调查发现，不用于验证研究假设、显著性、因果或真实需求。结果需与 `results/synthetic/README.md` 一同阅读。
