# 访谈数据结构预案（未实施）

当前没有访谈对象、录音、逐字稿、引语或访谈数据。本文件只预先列出将来经导师、学校审批和知情同意后，可能需要的数据表结构；不构成招募或实施授权。

## 最小结构候选

| 表 | 建议字段 | 边界 |
|---|---|---|
| 访谈记录索引 | 去标识化研究编号、访谈类型（学生/教师）、日期粒度、访谈方案版本、同意状态、转写状态 | 不在分析表保留姓名、学号、手机号或具体教师身份 |
| 主题编码长表 | 记录编号、段落序号、主题码、摘要（经最小化处理）、编码者、版本、反例标记 | 原始录音和可识别逐字稿分开受控保存；保存期限待审批 |
| 主题备忘 | 主题、证据范围、不同/反例、研究问题对应、解释边界 | 不以引语数量估计总体比例，不把个案视为普遍经验 |

是否需要录音、转写、双人编码、保存期限、访问名单和销毁流程均为 `PENDING`。未来引用须去除可识别细节并依审批核准。此处不生成任何虚构真人引语。
