# 样本量与可行性情景框架

状态：`SYNTHETIC_ONLY` / `PENDING_APPROVAL`。本文不指定正式 N、不作功效承诺，也不构成招募授权。

## 决策原则

正式样本量须在研究问题、主分析、测量质量、抽样框、学校许可和现实可达性明确后，由导师及必要的方法审阅共同决定。不能先定一个“看起来够大”的数再倒推设计；不能以竞赛期望或模型复杂度作为扩样理由。

## 需先冻结的信息

1. 主估计对象：描述比例、量表/评分分布，还是预先指定的关联参数。
2. 主分析单位及重复结构：学生、学校、课程或评分者；是否存在聚类及可用学校数。
3. 最小有意义差异/精度标准及其理论依据；不得从合成数据或方便样本倒推。
4. 预期缺失、无效答卷及任务子样本比例；当前均未知。
5. 可用学校与专业框、邀请许可、预计响应率；当前均未知。
6. 任务评分者数量与评分设计；评分一致性不能通过扩大参与者 N 替代。

## 仅供方案讨论的假设情景

| 情景 | 假设用途 | 可说明什么 | 不可声称什么 |
|---|---|---|---|
| 小规模可行性演练 | 检查流程、题目可理解性与耗时 | 工具与流程是否可运行（须先获批） | 总体推断、正式量表效度、稳定分组差异 |
| 多校描述性调查 | 估计预先定义的描述指标 | 在抽样与响应假设成立时的描述精度 | 自动代表全国财经本科生 |
| 关联分析扩展 | 检验少量预设关联 | 预先指定关联的精度/不确定性 | 因果影响或大量亚组结论 |

表中没有任何具体 N。未来任何 N 情景须给出输入参数、计算代码/公式、出处和敏感性范围，并经方法审阅；不得使用“建议样本量”字样，除非审批人明确批准。

## 停止条件

若可达学校过少、各校专业定义不可比、响应机制不明、核心测量仍不稳定或伦理/审批路径不清，优先缩小结论范围或延期；不得以便利抽样数据包装总体代表性。
