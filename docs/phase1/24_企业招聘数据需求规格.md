# 企业招聘数据需求规格（候选）

**当前状态：`RECRUITMENT_DATA_NOT_YET_AVAILABLE`。**未购买、联系供应方、登录、下载、抓取或编码任何岗位数据。本文件只定义未来判断是否可用的最低条件。

## 最低可用招聘数据集

不可缺少：岗位标题、岗位职责/描述正文、可解释的发布日期/年份、数据来源和版本/获取日期、明确许可状态。缺少岗位正文或来源/时间信息时，不足以作可复核的能力需求内容分析。

| 字段 | 最低要求 | 作用/处理 |
|---|---|---|
| job_id | 稳定的岗位记录标识或可去重字段 | 去重与审计；不得含求职者个人信息 |
| job_title | 原始标题 | 岗位族与范围筛选 |
| job_description | 职责/要求正文 | 核心编码文本 |
| posted_date/year | 至少年份，最好发布日期 | 时间覆盖与版本判断 |
| source_name/version | 来源名称及明确版本 | 覆盖、许可与复现 |
| access_date/license_status | 获取日期、授权/许可条件 | 合规判定；未知时不得分析 |
| industry | 行业字段（若提供） | 描述覆盖及分层 |
| location | 地区字段（若提供） | 识别地域覆盖 |
| education_requirement | 学历要求（若提供） | 描述岗位门槛 |
| experience_requirement | 经验要求（若提供） | 描述岗位门槛 |
| job_category | 岗位类别（若提供） | 辅助范围筛选，不代替正文判断 |
| salary | 薪资（若提供） | 非必需、不补造、不推断能力 |
