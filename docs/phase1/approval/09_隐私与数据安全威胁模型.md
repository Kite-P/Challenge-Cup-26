# 隐私与数据安全威胁模型

**DRAFT_NOT_FOR_USE** · **PENDING_INSTITUTIONAL_REVIEW**。当前未采集任何真人数据。

| 风险场景 | 可能影响 | 候选控制 | 残余风险/待定 |
|---|---|---|---|
| 问卷、任务、学校背景跨表重识别 | 参与者身份暴露 | 最小字段、单独保存映射、限制小单元输出 | 可识别组合阈值待审批 |
| 文件误传或云盘权限过宽 | 未授权访问 | 机构批准存储、最小权限、发送前核对与访问日志 | 系统和负责人待定 |
| 聊天工具转发原始文件 | 不可控复制/留存 | 禁止默认以聊天工具传输；审批渠道传输 | 应急处置路径待定 |
| 录音、转写或独特引文泄露 | 身份、观点或师生关系暴露 | 单独同意、去标识、限权、引文再识别审查 | 期限和销毁方法待定 |
| `research_id` 映射表泄露 | 重新识别参与者 | 映射独立加密、单人限权、避免与数据同目录 | 密钥管理待定 |
| 企业岗位数据超许可使用 | 版权/合同/隐私风险 | 按来源逐条审许可、只保留允许字段和用途 | 企业数据尚未获取 |
| AI 服务输入导致外部处理 | 参与者数据被第三方处理 | 不输入身份信息；须先明确服务条款/机构许可 | 允许工具与配置待定 |

发现事件时的负责人、报告时限和监管联系人均 `PENDING_INSTITUTIONAL_RULE`。不得把“尚未发现漏洞”表述为零风险。
