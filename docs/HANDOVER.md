## 研究主题与证据分工

财经相关专业本科生在研究型学习中使用生成式 AI 的行为；关注使用环节、信息辨识与评估、方法适配、独立研究决策、任务内表现和培养需求。问卷是主体调查证据；约10分钟短任务及学生/教师访谈为辅助；企业招聘需求侧保留为已确认补充模块，目前没有招聘数据或结果。研究不预设 AI 的效果方向。短任务的校园学习资源情境不是研究主题。

## 模拟流程

`data/synthetic/` 与 `results/synthetic/` 只验证代码、格式和内部流程，不是真人或企业研究数据。复现方式：

```powershell
python -m compileall -q src tests
python -m src.run_repo_checks --pipeline
```

本轮原则上不修改模拟生成/分析程序。若未来变更再运行测试，结果仍不得写成研究发现。
