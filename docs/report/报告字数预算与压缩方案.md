# 报告字数预算与压缩方案

**用途：**内部规划，不是竞赛官方字数要求。当前届次、赛道和提交规范均未确认；以正式规则为准。

## 当前完整稿与最终压缩目标

- 完整内部 Master Draft 的规划量级：约 20,000–24,000 中文字（包括真实调查完成后的结果、讨论和必要附录说明）；这不是当前稿实际字数，也不是必须达成的指标。
- 如正式规则或导师要求更短，工作压缩目标约 15,000 中文字；只有在确认官方限制后再定最终范围。
- 当前 v0.1 只把第1–4章写成可审阅草稿，数据章节是证据占位。不得为达到字数目标而预写结果、重复综述或增加构念。

## 初步篇幅预算

| 部分 | 完整稿预计区间 | 压缩优先级与条件 |
|---|---:|---|
| 摘要、关键词 | 500–800 | 结果取得后一次写成；依规则压缩 |
| 第1章 问题提出 | 1,800–2,400 | 保留问题、对象、范围和研究问题；删泛化AI背景 |
| 第2章 文献与分析视角 | 2,800–3,600 | 只保留能支持本研究设计/解释的文献；不逐篇摘要 |
| 第3章 研究设计与方法 | 2,400–3,200 | 完整披露抽样、工具、伦理和分析，不能为省字删掉边界 |
| 第4章 工具形成与质量控制 | 1,300–1,800 | 合并重复的工具版本叙述，保留关键审阅和质量证据 |
| 第5章 实施与样本 | 1,200–1,700 | 依真实样本流填写；未实施则不填造 |
| 第6章 问卷结果 | 2,400–3,000 | 只围绕核心问题呈现必要表图和分母 |
| 第7章 任务结果 | 1,500–2,000 | 分维度报告，不做总分或超范围解释 |
| 第8章 访谈结果 | 1,500–2,000 | 主题、条件、反例；引文少而可追溯 |
| 第9章 企业补充证据 | 0–1,200 | 仅在有许可数据且确实符合竞赛规则时纳入，否则删除本章或简述不纳入原因 |
| 第10章 讨论、建议、限制 | 2,200–3,000 | 每条建议回指证据；明确相关与因果、样本与总体边界 |
| 参考文献与附录 | 按规则 | 核验格式和材料公开/许可条件，不用附录绕开字数规则 |

## 压缩顺序

1. 优先删去重复背景、泛化技术介绍和与核心问题无关的理论；
2. 将相同样本描述合并，表格与正文分工，正文解释关键发现而非复述全部数字；
3. 企业需求侧若缺乏可用证据或合规性不明，整块降为局限/后续，不挤占学生主线；
4. 不删除审批、抽样、分母、缺失、工具版本、评分质量和结论边界等可审计信息；
5. 最后按正式赛规压缩，而不是提前用未经核实的往届格式限制研究设计。
