## 第一章 问题提出

### 1.1 研究背景

生成式人工智能已进入学生查找线索、整理材料、比较方案和组织表达等学习活动。对研究型学习而言，关键问题不只是学生是否接触某种工具，还包括他们在任务的不同环节如何提出问题、核查信息、判断输出适用条件、选择方法，以及由谁承担最终决定。现有研究同时讨论了生成式人工智能可能提供的学习支持与可能带来的过度依赖、认知外包和主体性风险；研究情境、干预方式和结果指标并不相同，不能简单合并为“AI有益”或“AI有害”的单一结论[1-4]。

本科生科研训练研究则提示，科研参与、课程实践、指导支持和学生实际承担的任务角色可能彼此不同。参与过项目并不自动意味着具备同等研究能力；不同专业、学校和培养项目中的经验也不能直接外推到财经相关本科生总体[5-12]。因此，本研究拟把研究经历作为背景信息加以描述，不将项目身份或经历数量直接等同于能力。

本项目所说的“财经相关本科生研究型学习”，指学生在课程研究作业、调查报告、创新训练、学术科技竞赛研究任务或导师课题等情境中实际参与研究步骤的经历。项目拟关注生成式AI参与研究过程的方式，以及这些方式与信息辨识与评估、方法理解与适配、独立研究决策和特定任务表现之间的关系。校园数字学习工具与学习资源仅作为短任务中的中性、低专业门槛情境，使不同财经相关专业学生无需专业软件知识即可完成问题界定、材料判断和方法选择；研究并不考察某个平台的使用效果。

### 1.2 现实问题与研究缺口

首先，“是否使用AI”难以描述研究过程。相同的使用频率可能对应不同环节、不同核查方式和不同决策责任；未使用AI也可能是基于任务要求或个人选择，不能直接解释为能力不足。有关大学生使用深度与类型的研究为区分协作过程提供了设计参照，但类型划分依赖具体样本和测量，不宜直接移植为本项目的稳定画像或优劣等级[14-15]。

其次，学生自我报告与具体任务中的表现并非同一证据。自信、回忆中的行为、一次情境任务的书面作答和访谈中的过程说明各有测量边界。导师提供的文献中缺少直接验证本项目所拟“自评经历—特定研究设计任务表现”关系的同构工具或结论；这是待研究问题，而不是可以预先填补的结果（见《导师文献证据地图》及文献到设计映射）。因此，拟议设计将问卷作为学生经历与协作方式的主要证据，以短任务观察有限的任务内表现，并以访谈补充解释过程，三类证据分开报告。

再次，既有研究常针对特定学科、课程或培养项目。翻译硕士学习动机、健康信息采纳、会计教育评价等研究能够提供工具组织或研究流程的参考，却不能直接提供财经相关本科生跨专业研究设计判断的题项、效应或结论（导师指定三篇论文对照，PDF 阅读器页码见对应审计笔记）。本研究因此不移植 Q 方法、技术接受模型、健康信息采纳模型、信任中介/调节结构或其量表，而以明确的研究任务步骤和证据边界形成候选工具。

### 1.3 研究目的与研究问题

本项目拟在适用审批、导师审阅和渠道许可完成后，描述财经相关本科生在研究型学习任务中与生成式AI协作的方式，并探索这些自报经历与三类研究过程表现及特定任务作答之间呈现的关系。研究不预设关系方向，不声称AI导致能力变化，也不把一次任务概括为完整科研能力。

拟议研究问题如下：

1. 财经相关本科生在研究型学习任务中如何使用、核查、修改、拒绝或不使用生成式AI？这些行为在不同任务环节如何呈现？
2. 学生在一项固定、低专业门槛的研究设计短任务中，如何界定问题、评估材料、匹配方法、说明结论边界并作出最终方案？
3. 问卷中的协作方式与经历变量，与短任务各分项表现呈现何种关联；学生与教师访谈如何补充解释其中的过程、条件和反例？
4. 在取得合法、可核验的招聘岗位文本后，企业岗位能力需求画像呈现哪些主题；这些主题与学生端研究过程及任务表现可作哪些 `DIRECT`、`PARTIAL` 或 `NO_DIRECT_MATCH` 的结构性对应？该问题目前仅为已确认的补充研究设计，数据状态为 `RECRUITMENT_DATA_NOT_YET_AVAILABLE`，结果状态为 `NOT_ANALYZED`。

上述问题为候选，不表示变量、样本或分析已冻结。若无法取得适当审批或可行样本框，应重新评估项目可行性，而不是降低合规条件。

### 1.4 研究意义与范围

本研究的潜在价值在于把AI使用从简单的有无或频率描述，推进到任务环节、输出处理和决策责任等可解释过程；同时通过独立的任务产物观察有限的研究设计表现，避免把自我评价直接当成能力测量。该价值目前是研究设计层面的预期，不是已经证实的学术或教育效果。

研究对象拟为财经相关专业本科生，具体学校、专业代码、年级、总体边界和是否设置研究经历门槛均 `PENDING`。学生问卷拟为主要证据；短任务、学生访谈、教师访谈为互补证据。企业岗位能力需求画像是导师已确认纳入本项目的补充模块；当前招聘数据、来源版本、许可和岗位文本尚未取得，状态为 `RECRUITMENT_DATA_NOT_YET_AVAILABLE`，结果为 `NOT_ANALYZED`。不得因此把该模块降为任意可删的可选项，也不得声称画像或供需差异已形成；若无法取得合法数据，须记录风险并由人工决定应对。赛事赛道、学校资格和当期格式要求仍待正式规则核验。

## 第二章 文献与分析视角

### 2.1 本科生科研经历与研究能力培养

本科生科研参与研究覆盖人文社科调查、重点实验室课程、拔尖人才培养和特定学科创新训练等不同安排[5,7,9-11]。这些研究提示，研究机会、任务参与和指导环境需要分别描述；其对象和培养机制具有情境性，不能仅凭项目经历推断学生研究能力，也不能把特定学校样本视为本项目的先验总体。与生成式AI辅助科研课程、文献综述或研究方法教学相关的案例可帮助识别任务环节，但教学案例本身不构成本项目的效果证据[8,15-16]。

据此，问卷拟记录最近一项研究型学习任务及学生实际参与环节，研究经历用于描述或谨慎分层，入组门槛尚未确定。短任务只覆盖问题、材料、方法和限制等有限步骤；其表现受任务材料、阅读速度、书面表达、工具熟悉度和时间条件影响，不能外推为完整科研创新能力。

### 2.2 生成式AI与学习过程：可能收益及边界

导师提供的材料包含管理教育、科研课程、研究方法教学、批判性思维、自主学习、学生使用类型和学习效果等不同研究问题。相关文献对支持作用、风险和学习结果的讨论并不完全一致，其结论受任务设计、样本、工具和结果变量影响[1-4,8,13-14,16-22]。特别是综合研究或理论文章所讨论的平均趋势，不能代替本项目的样本证据；对使用深度或学生类型的研究，也不意味着存在跨情境稳定的“好/坏使用者”类别。

本研究据此采用开放方向的描述与关联问题：记录学生在哪些环节使用或不使用AI、是否追问条件与依据、如何处理输出、是否由本人作最终选择。它不把使用频率合成为未经验证的协作质量总分，也不预设使用AI必然提高任务表现。若未来获得横截面数据，结果只能称为关联；自报中的核查行为仍不是对实际交互过程的完整观察。

### 2.3 信息辨识、方法适配与独立研究决策

现有批判性思维、自主学习和认知发展研究与本项目关注的问题相邻，但不等同于本项目所定义的任务行为。为避免把宽泛心理构念直接搬入问卷，本项目将“信息辨识与评估”操作化为在具体研究问题下辨认材料相关性、来源与统计口径、主张依据、证据支持范围及需要进一步核查之处；“方法理解与适配”关注研究问题、材料、方法和可作推断之间的匹配；“独立研究决策”关注学生是否能说明最终方案及其取舍依据，而不是是否拒绝AI或独自完成任务。

这些是当前工作定义，不是成熟量表名称。导师材料没有提供可直接复制且与本任务同构的测量工具，故候选问卷、短任务和访谈以分项行为与具体过程为主，不合成为单一能力总分。任务评分的五维锚点仅针对本次作答，`NOT_SCORABLE` 与 0 区分，且不因表达长度或AI建议采纳方向加减分。

### 2.4 研究设计与证据链

导师指定的三篇硕士论文分别使用探索性 Q 方法后续问卷、结构化问卷和以构念模型为基础的调查；其对象、构念和模型均与本项目不同。本项目可借鉴的限于研究问题先于工具、问卷说明与跳题清楚、访谈围绕具体经历、工具修改留痕，以及测量结构与分析方法相匹配。Q 陈述、TAM题项、健康信息信任模型、中介/调节假设和样本量均不移植。页码依据 PDF 阅读器页码，详见《三篇硕士论文研究设计对照》和《三篇论文附录工具对照》。

分析视角不是因果模型，而是“AI协作方式 → 信息辨识与评估 / 方法理解与适配 / 独立研究决策 → 特定任务中的可观察表现”的证据组织线。箭头表示研究问题与证据的安排，不代表因果方向。企业需求侧与学生侧之间将来如能取得许可，也只能作内容映射，并须报告 `DIRECT`、`PARTIAL`、`NO_DIRECT_MATCH` 及其编码依据，不能直接计算未经验证的“能力差距”。

## 第三章 研究设计与方法（候选方案）

### 3.1 设计类型与证据分工

候选方案为以学生端问卷为主的描述性、探索性调查，并结合一项短研究设计任务和半结构访谈。若将来形成适当样本，问卷可描述协作行为、研究经历和支持情境；短任务用于观察固定材料下的有限作答表现；学生访谈用于解释个体决策过程，教师访谈提供一般教学观察。三类证据不自动合并、不互相替代，也不构成实验或因果识别设计。是否开展问卷、任务和访谈以及是否关联记录，均须另行审批和确认。

### 3.2 研究对象与抽样

目标对象暂定为财经相关专业本科生，但院校范围、专业代码映射、年级范围、目标总体、可用样本框、招募渠道、样本量和跨校安排均为 `PENDING`。研究经历是否为入组条件尚待导师确认；现有方案倾向把经历类别、角色和深度作为描述信息，而不是先验能力门槛。不得把便利样本描述为全国代表样本，也不得在没有样本流记录时报告响应率或总体推断。

未来若获准实施，报告需逐项记录目标总体、实际接触渠道、邀请/回应/纳入流程、排除理由、缺失情况及跨校许可。正式 N 需基于可达总体、主要描述目标、资源和批准条件另行确定；本稿不填样本量。

### 3.3 候选工具

**学生问卷。**v0.5 候选包括核心题组与可选题组，覆盖近期研究型学习任务、实际参与环节、AI使用阶段及过程、信息处理策略、支持情境和有限反馈。问卷以经历和行为自报为主，不是AI态度量表，也不测量稳定研究能力。未使用、记不清、不适用和拒答需按题目规则区分。

**短任务 A。**约10分钟的候选任务使用三张合成材料卡：匿名留言、平台访问次数摘要、一门课程的自愿反馈。参与者需界定研究问题、逐卡评估可支持内容和缺口、选择先行步骤与方法、说明结论边界并给出最终方案。该任务不是对校园平台的实证调查，也无唯一标准卡。目标时长未经真人计时。

**任务评分。**候选五维为问题界定、信息辨识与评估、方法理解与适配、限制与结论边界、独立研究决策，每维0–2或 `NOT_SCORABLE`。不合计、不排名；不按AI使用、是否采纳某条建议、文笔长度或术语数量计分。评分一致性方案、评分者数量、仲裁规则及培训仍待确认。

**学生与教师访谈。**两份 v0.3 提纲分别围绕学生的实际研究步骤与教师的一般观察，均为约20–30分钟的设计估计，未验证。学生不需提供AI聊天记录；教师不提供可识别学生材料、内部招聘资料或企业结论。访谈对象数量、记录方式、录音同意和引用规则均待审批。

### 3.4 生成式AI条件、数据最小化与伦理边界

候选任务允许但不强制使用参与者平常使用的生成式AI；不设置 AI/no-AI 实验组。未来若经审批记录过程，只考虑是否使用、使用环节、是否追问理由/条件、是否核查依据、是否修改/拒绝建议及最终决定者；不收集完整提示词、聊天记录、账号或屏幕录制。具体平台可能采集的技术元数据尚未核实，不能承诺完全匿名。

当前公开核查状态为 `OFFICIAL_PROCESS_NOT_FOUND`，这不表示免审。适用机构责任部门、是否需要伦理审查/备案、知情同意、数据用途、保存期限、访问权限、撤回界限和销毁程序均未确认。竞赛合规与研究审批为两道独立门槛；在取得明确结论、导师审阅、获准渠道和数据管理方案前，不得接触参与者或开展任何收集。

### 3.5 分析计划与解释规则

候选分析先报告样本流、背景和协作行为分布、题项缺失与数据质量；问卷自报、任务分项和访谈主题分别呈现。只有样本结构与预先定义的问题允许时，才考虑少量简单关联或分层描述。默认不采用 SEM、潜类别、聚类、中介、调节或复杂因果模型；不为追求复杂度新增构念。访谈用于解释过程、条件和反例，不用于估计总体比例。评分一致性属于测量质量，不是参与者结果；若数据结构不支持计算，应报告不可估而非强行给出指标。

所有结论须按证据类型限定：横截面问卷只能支持关联；自报不能等同实际能力；单次任务只描述“在本任务中的表现”；教师观点不能替代学生证据；岗位文本只能描述所分析且获许可的文本。模拟数据仅检验软件流程，不能进入报告研究结果。

## 第四章 工具形成与质量控制（候选方案）

### 4.1 文献与导师论文审阅

工具开发以导师提供的参考文献和三篇指定论文为方法参照。已完成的桌面审阅记录了研究问题、方法、附录工具、页码和迁移边界：借鉴对象/用途/流程说明、跳题可读性、具体经历追问和版本留痕；不复制原论文题干、模型、样本数、结果或同意书中的联系方式。导师文献包中有两项来源无法可靠提取或解析，不用于正文实质论证；其余引用信息仍须回到原文核实。
