# 仓库中文书写规范

1. 面向导师、评审和项目成员的说明、标题、表格栏目及操作指引使用简体中文。
2. 研究变量、状态码、软件名称、专业术语、正式机构名称及学术文献题名按原样保留；首次出现的必要术语可附中文解释。
3. `PENDING`、`UNKNOWN`、`PILOT_BLOCKED` 等状态标识不得改写其值；首次出现时紧邻给出准确中文释义，不得把待确认写成已确认。
4. 网址、DOI、文件路径、文件名、稳定标识、字段名、代码、命令及数据结构保持原样。
5. 只翻译便于阅读的叙述，不得借中文化改变研究设计、数据事实、来源状态、权限判断或历史记录。
6. 文档须明确区分已确认事实、暂定方案、历史状态和待确认事项；不得把草案表述成已批准或已实施。
7. 新提交说明使用简体中文；既有提交历史不改写，以中文对照文档辅助阅读。
