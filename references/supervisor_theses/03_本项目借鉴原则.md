# 本项目借鉴三篇论文的原则

## 借鉴什么

1. **先界定对象与问题，再落到题目。**工具围绕财经相关本科生的研究型学习经历编制；校园数字学习工具与学习资源仅是短任务中的低专业门槛情境，不是本项目研究主题。
2. **工具之间各有分工。**学生问卷承担主要的经历与协作方式描述；约10分钟短任务观察有限、具体的作答表现；学生访谈解释个人决策过程；教师访谈补充一般教学与指导观察。它们不是四份平行量表。
3. **把题项、跳题和分析对齐。**每个题组注明用途、适用对象和缺失情形。行为事实、自报策略、情境作答和自我感知分别呈现，不合成为未经验证的能力分数。
4. **保留版本证据。**导师意见、认知反馈和修改理由分别记录。预测试只是未来候选步骤，本轮不实施、不预设人数，也不以一轮前测自动证明效度。
5. **从证据到报告建议。**报告先交代调查设计、样本与质量控制，再呈现实际结果；所有建议须能回指经核实的调查、访谈、任务或文献证据。

## 不照搬什么

- 不把项目改成 MTI 学生学习动机、GenAI 技术接受或健康信息采纳研究。
- 不照搬 Q 方法、TAM、MAIN、心理信任模型、因果假设、中介调节模型或相应长量表。
- 不把导师长期课题申请书中的所有研究专题原样移入大挑社会调查。申请书仅作为问题背景、对象范围和既有文献基础；本项目以可审阅的调查问题、简明工具和可追溯证据为界。
- 不移植论文的样本数、有效率、显著性结论、总体判断或对策成效。
- 不因论文采用了某种统计检验，就对本项目所有事实题、类别题、跳题和开放题计算 Cronbach α、KMO 或因子结构。

## 版本与实施边界

本轮生成的问卷、任务、访谈和报告均为候选稿。论文可作为方法参考，但不构成导师批准、学校伦理/审批结论、渠道许可或数据管理批准。当前 `CURRENT_CYCLE_RULES_PENDING`、`OFFICIAL_PROCESS_NOT_FOUND`、`WAIT_SUPERVISOR_EXTERNAL_CONFIRMATION`、`RECRUITMENT_DATA_NOT_YET_AVAILABLE` 均保持原值；研究实施状态保持 `PILOT_BLOCKED`。
